# 〔对象〕价值审计：专业版

审计日、对象/版本、发表时点、审计目的；实际阅读和调查范围链接独立记录。

专业正文单独执行[写作要求5.1节](../references/explanatory-depth-and-public-writing.md)：评价原则、未作答的待补问题、纯边界/流程声明合计字数M不得超过实际分析字数A的1%。正文摘要、表格和结尾同计；分类/计数存配套记录。具体影响判断的事实限制随推导说明，不以删关键限制或凑篇幅通过。

全文按[短句与通俗表达要求4.1节](../references/explanatory-depth-and-public-writing.md)写作：每句一个主要意思，缩写和术语首次出现先解释，复杂因果拆成连续步骤。专业读者也不应被迫从堆叠从句和行话中自行还原推导。

## 决策摘要

最重要判断及原因；科学探索、工程验证、产品化、推广各支持何种行动；最可能改变决定的具体事实。未知仅标出它改变哪项判断。

直接给审计者的投入取舍：评价目标、主导瓶颈、输入的边际作用、可行替代和当前行动。不能只列技术优缺点或补证义务。具体写法按[交付要求](../references/report-delivery.md)。

## 领域真正要解决什么

以非本领域决策者能理解的正文展开。按[解释深度要求](../references/explanatory-depth-and-public-writing.md)回答：

先完成[领域解释与因果分析](../references/field-understanding-and-causal-explanation.md)底稿，再写正文。关键系统中每个部件的职责、实际瓶颈、同任务替代及测量分母须讲清；不能只在表格里列性能指标。

- 为什么产生这个知识问题或使用需求？真实任务、输出质量和系统边界是什么？
- 发表时已经能做什么，最接近先行怎样工作，卡点来自哪种机制/工艺/信息条件？
- 当前实际系统怎样做，哪些路线为何进展、改换或退出？当年与现在不能混为一谈。

解释决定性概念和参数的意义，先让读者理解问题与现有能力，再给路线/背景比较表。表后解释差异及其对投入判断的作用，不只列历史或领域热度。

### 应用场景的工业现实基线（存在应用主张时必写）

先具体说明谁在什么生产/服务任务中遇到什么瓶颈、现在用什么方案、为什么现有办法不够，以及证据来自买方/运营方/制造/采购的哪些原始记录。区分实际运行数据、合同/采购、资格材料、行业研究和企业宣传；说明来源关系及它能支持到的交易/采用阶段。再据可核任务分母、替代支出、切换/认证成本和交付条件推算未来市场。不能用论文群体的需求陈述、新闻热度或行业总规模替代这个基线。若查遍适用且可访问的工业线索仍找不到有效市场证据，正文直接写明所查行业与任务，以及为什么这些材料不足以支持该应用价值/扩张经费理由。

## 输入贡献究竟在哪里

### 成果本体与运行过程

介绍作者实际制成/证明/测得的对象；结构、制造/准备或论证步骤、工作与读出过程、输出、尺度和工况。解释关键部件做什么以及如何配合。对决定性的图表给文字解读，必要时画有来源的自制示意；不能让设备名和工艺缩写代替介绍。

### 具体新意与证据

最近先行已经会做什么 → 本工作具体改变哪一步 → 为什么这一步困难 → 新机制/组合怎样起作用 → 实验/证明怎样验证 → 剩下哪些边界。指出已有原理/部件和新增部分。分别判断发表时增量、可靠性、复用和当前重要性，不用“首次”“平台”“极高性能”代替细节。

### 同类与替代为什么可比

分别介绍最近学术先行与同任务最强现实替代的结构/原理、性能条件和代价，说明比较目的。让读者理解对方如何处理同一困难。表格可列对象、机制、已实现尺度、终点、资源与未解决约束；表后解释主导差别。

## 决定性论证

按重要性组织若干[论证单元](decisive-argument-template.md)。展示事实、模型/推导、参数、强替代、最强异议、结论和经费含义。适用时做删除/替换/补齐、规模和有利阈值分析。

每个主导瓶颈展开：机制/事实起点 → 对合格输出的影响 → 规模或工况怎样放大 → 补救代价 → 强替代如何处理 → 本输入改变多少。说明瓶颈相互作用；不能以“可靠性/成本/产业化有挑战”收束分析。

纳入专业社区/实际从业者提出的关键问题：技术内核是什么、原文或实测如何核查、最强回应改变了什么、最终采纳/限定/驳回哪些部分。不能用意见数量和“存在争议”替代裁定。

## 成本、科学回报与资源选择

区分历史支出/当前复造/下一阶段预算/终端收入。成本模型含工作量与范围。评价具体科学回报及替代获取方式，不用未有市场等同科学零值。对下一笔钱给明确用途、阶段门和退出条件；没有相称资料时不编精确历史ROI。

## 宣传与决策误推

原词或数字 → 容易误推出什么 → 技术上为何不成立 → 会怎样改变资金行动。没有传播/决策记录时标成风险路径，不断言实际误导已发生。

## 综合裁定与翻转条件

分开事实、科学增量、应用贡献与资金行动。明确列所查行业/任务；没有有效市场证据就直说。原理反证给具体理由，不用未来可能性稀释结论。

## 附录索引

研究底稿；原件与阅读范围；搜索/覆盖；参数/计算脚本及输出；标准/奖励规则（适用时）；结构化报告及专业—大众关键判断映射。记录哪些检查实际运行。
