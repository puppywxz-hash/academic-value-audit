# 来源覆盖与路线闭环记录

对象/结果层：〔具体成果与可观察结果〕  
审计截止日：〔日期〕  
结论要支持/反驳的主张：〔窄而可核验的表述〕

填写规则：每个审计结果层单独建表。先发现来源，再逐入口查询。来源家族名称、入口列表或搜索引擎摘要都不等于实际覆盖。具名、适用、可访问的来源尚未查询，必须保留为“待查”，整个路线不得标作闭环；不得以“没有全球主体/交易名册”豁免任何路线。检索结果过大时写明结果数、过滤和抽查/筛读规则；不可声称读过未实际查看的记录。状态只能用：已查询并筛读／已查询、结果集过大（说明处理）／访问受阻并完成替代尝试／经对象级证据确认不适用／待查。

结束前逐项确认：

- [ ] 从成果 DOI/题名/作者/机构/专利/资助标识向外追踪。
- [ ] 从终端任务/产品功能/买方/用户词向内发现其他架构与供给方。
- [ ] 检查该类结果通常留下的官方、交易、部署、用户和生命周期记录。
- [ ] 主动查询替代、负结果、未采用、停止、召回、失败和退出。
- [ ] 由来源目录/API、地区登记和实际命中继续发现来源；没有把来源家族勾选当作逐入口检索。
- [ ] 所有能改变事件是否发生或是否归因的具体线索，已追到原始记录或保留阻断。
- [ ] 相关“待查”项和可执行覆盖债务为零；所有受阻/不适用项都有根据和替代路线。
- [ ] 最后从独立于原研究/宣传链的来源做反向挑战，记录新增线索和处理结果。

## 六、调查状态与结果措辞

- 来源调查状态：〔可得来源调查已闭环／未闭环／部分受阻〕
- 结果总体状态：〔总体闭合且捕获能力已说明／开放〕
- 观察到的目标可归因结果：〔按阶段逐项列出；没有则明确写未发现〕
- 结果层裁定：〔已支持／被具体机制或对照反证／已查行业未找到有效证据支持，不作为扩大投入依据／调查未完成并继续执行〕
- 可说的事实范围：〔说明地域、时间、来源记录和归因覆盖〕
- 不可外推的命题：〔世界上所有隐蔽事件都不存在、全球精确市场数、未查证收益、其它价值层等〕
- 下一项会翻转结论的具体证据：〔如无已知项也明说“本轮覆盖债务清零；未来新证据仍可改判”〕
