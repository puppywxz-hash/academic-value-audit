# 原始资料获取与证据提取方法

涉及资金/经济性时，除本节原件取证外，必须按 [成本与需求重建](cost-demand-reconstruction.md)追踪资助/采购标识、金额口径、装置规格与可比范围。无法取得总账不等于无法取得分项、约束或阈值输入；实际尝试与未执行分开。

按取证任务使用；最终依据适用 [质量协议](evidence-quality.md)。检索结果用于定位，原始材料及取得范围才进入裁定。

## 1. 先写取证问题

只有姓名/组名/奖项/项目题名或简介时，先按 [输入发现分支](input-discovery.md)定位具体对象、成果形式和关系再取原件；用户不用提供全文。人/团队按实际角色/时期归属，项目无全文只读可见目标/报告与关联成果。用 [发现模板](../assets/discovery-record-template.md)或等价台账记录下一项，不从主题命中直接确认成果属于对象。

以 claim/context ID 建立一行任务：要核对的确切命题、时间/地域/用户/工况、竞争解释、什么记录能够区分、缺失会限制哪项结论。将领域术语转成任务/产品/功能词，保留旧名称、型号、法人和替代路线。

例：查“材料 A 有市场价值”需拆成材料身份、具体部件、付费使用、用户增量收益和可持续成本；查“成果新颖”需拆成核心机制、事前先行工作和实质差异。不能用一个宽泛材料词搜出的新闻集合回答所有问题。

涉及实际/潜在产业或社会价值，先按 [需求与影响流程](demand-and-impact.md) 建立独立需求分支。原始材料取得是工具能力，任务/残余问题/采用与效果的判定是另一项分析；学术检索或通用市场报告不替代它。

系统搜集执行 [非学术搜索协议](nonacademic-search.md)：建立问题—记录产生者—机构/数据库—查询—取得/覆盖矩阵，用功能、同义词/分类、原编号/法人和事件追踪迭代，保存去重关系及停止理由。借鉴现成市场技能、灰色资料与专利景观方法，不以关键词命中清单代替取证。

涉及标准/测试/认证门槛，按 [标准专项流程](standard-retrieval.md)取得官方编号/版本/状态及原条款、约束来源和可比性；“目录可查”与“必要条款已读”分开。涉及奖励按 [奖项适配](award-assessment.md)找正式范围、历史规则/细则/当年文件及底层成果，不能用获奖公告或当前规则替代。

## 2. 按问题选择原始记录

| 要核的内容 | 优先定位的原始记录 | 进一步必须核对 |
| --- | --- | --- |
| 对象及历史增量 | 原文/预印本版本、方法/SI、早期论文、代码、当时产品/技术文件 | 身份/日期、具体机制/条件差异；引用图仅作线索 |
| 实验有效性 | 方法、图例、数据、重复记录、对照、修正/撤稿通知 | 独立单位、选择/排除、原始/加工数据；没有通知不表示已证真实性 |
| 实际需求/要求 | 需求方任务、现行原条款、验收规范、使用/维修记录、招采技术附件 | 提出者、强制性、版本/地区、层级/失效与合理性；目标值不当已实现需求 |
| 技术标准 | 官方目录、正式标准/修订/勘误、引用条款、法规/合同采用依据 | 部分号/版本链/状态、适用范围、规范性与资料性、测试/验收和现实需求；目录不当正文 |
| 商业兑现 | 客户原始记录、验收/运行/复购、披露及分部附注、采购成交和延期/退出 | 型号、材料/路线、关联交易、补贴、付费与后续净收益；中标不等于验收 |
| 成本/制造 | 对应规模的设备/材料/能源输入、质量/良率、报价条件、实际产线/成本记录 | 报价与成交、产能与产量、实验级与量产价、BOM 与全生命周期 |
| 资助/奖励/专利 | 官方项目/预算/拨付/验收、获奖范围及底层成果、专利原文/状态 | 额度口径、分期/共同资助、实际支出；授权事件不验证性能/实施 |
| 奖级贡献依据 | 适用年度/类别/等级的正式规则、实施细则/指南/评分文件、提名范围及支撑原件 | AND/OR、资格/等级/偏好、时间截止与权重出处；授奖不循环验证贡献，未读评分表不编权重 |
| 社会效果 | 目标群体/结果原始统计、可信对照、实施与分配记录 | 反事实、选择/混杂、总变化与成果贡献；受访意见不当总体发生率 |

官方、工业和客户来源也可有利益关系；“原始”意味着接近观察，不意味着无偏。采用六渠道搜索矩阵，记录查到的支持、反证、边界与失败，按同一相关性规则筛选。

可参考 [Crossref REST 元数据范围](https://www.crossref.org/documentation/retrieve-metadata/rest-api/) 发现持久标识/更新；[OpenAlex 当前认证说明](https://help.openalex.org/api/authentication/) 只用于实际服务路由；[SEC EDGAR API](https://www.sec.gov/search-filings/edgar-application-programming-interfaces) 可定位美国披露原件。中国公告/采购、专利、项目和标准走对象所属的官方门户/原文件；先核门户与当前检索方式，不猜通用 API。

非学术查询按任务选择公开目录：[中国政府采购网](https://www.ccgp.gov.cn/xxgg/)定位需求附件、变更/成交、合同与验收线索；[巨潮资讯网](https://www.cninfo.com.cn/new/index?islogin=false)定位对象年报/分部、交易和风险披露；[市场监管总局召回](https://www.samr.gov.cn/zlfzj/qxcpzh/index.html)定位型号和失效线索。国家/地方/行业行政统计定位目标人群、使用或产业分母；用户提供的运行/维保/费用记录须核其定义、权限及完整性。目录索引不当已读对象原件，召回/投诉不直接给发生率，付款/客户净收益未公开时保持未知。

## 3. 查询、发现与覆盖

按原命题、功能/需求、竞争路线、失败/边界、历史兑现分别构造查询。相关领域需中英文/当地语言和旧术语；人/组按机构时期与 ORCID/公开履历消歧。日志保留数据库/页面、完整查询、过滤器、日期、结果数量若实际可见、游标/页范围、排除理由和失败。官方目录、作品主页与独立索引交叉定位，重合不是独立实验。

需求端查询示意（不是已执行结果）：任务/产品 + 使用工况/维修/停机/运行成本；同类项目 + 需求调查/技术附件/成交合同/验收；替代方案 + 兼容/维护/更换；用户/运营方 + 未采用/取消/停用及原因；社会结果 + 目标人群/暴露分母/对照/覆盖。先不限定成果品牌，再对已找到的具体型号/主体/时间回溯。未采用原因需原记录，不由负面关键词替代因果分析。

大列表先分页保存发现清单，再按既定范围处理；引用网络、相似推荐和高被引结果不作为全集。新发现证据改变身份、场景或基线时修订取证问题并记录，不能只沿首次搜索印象追加支持材料。

检查覆盖的结束条件：已纳入关键主张的相应渠道已执行或说明为何不可用，决定性矛盾已处理，原始记录/缺失影响已有定位。未知总体和网络限制不叫穷尽；仍有纳入工作未处理时继续分批，而不是以临时搜索无结果结束。

## 4. 获取与留存

合法使用用户文件、出版商 HTML/PDF、作者/机构仓库或已授权访问；SI/更正与正文关联。下载后确认题名/版本、文件类型和内容，登录页/错误页不能当原件。需要复核的合法文件保存来源 URL、取得时点、实际可见范围及可用哈希；不将全文访问许可扩展为公开复制许可。

访问失败按原因记录：未开放/权限、链接失效、限流、验证码、格式/解析失败等；切换合法原件或内容等价版本，声明差异。只靠索引摘要就保持 source_limited。跨技能权限规则见 [路由](capability-routing.md)；本 skill 默认相关 SI 不代替下载器所要求的用户选择。

## 5. 从原件提取可用数据

1. 文本 PDF 优先保留物理页、原始文字和结构；HTML 保留章节/表/图/版本；扫描件 OCR 后仍指向原页。
2. 建立工作证据卡：确切主张、实验/记录、对照、结果、独立单位、定义/单位、误差类型、测试条件、原始位置、可见/缺失范围。
3. 对决定结论的数字回看原图/表及图例、方法/SI，检查负号/指数/小数、单位倍率、样本数、误差条、印刷页与 PDF 页。多栏、合并表头、脚注不能只靠提取文本解释。
4. 图像数字化仅在无可用表/数据且能识别坐标/尺度时使用；记录线性/对数轴、校准点、区域、提取精度和重叠/分辨率影响。无法辨认时不给精确数；均值曲线不能倒推出独立原始样本。
5. 参数 P 链接原始 E/位置及转换步骤；报告的数与自己重算的数分开。样本/批次/文章/设备/客户计数单位明确。

轻量原页提取可用已有 pdfplumber/pypdf/Poppler；大批学术结构可选 [GROBID](https://github.com/grobidOrg/grobid)，但其 TEI/引用提取不保证表格数据、公式或材料身份正确。不要在普通审计重写解析器。

## 6. 定性材料与矛盾

建立“竞争解释—应观察到的记录—实际证据—来源条件”表。把同一宣传链、同一原始观察、真正不同记录分开；访谈、行业报告、客户证词保留选择方式、时间、角色、问题和关系。只有一个专家意见不代表全行业共识；模型的专业口吻不算专家证据。

冲突先查版本/定义/工况/尺度/样本/利益及披露范围，再判断是否实质相反。无法识别优劣时保留分歧，并说明哪项观察可区分；不能多数表决，也不为“平衡”给弱批评与匹配实测相同权重。无需货币化的知识贡献可按严谨推导/反例/可复用资源评价。

接回现有 E/S/quality_audit 和 M1–M9；没有足够原始记录时明确限制应用、创新或投入判断，不能靠下游生成的流畅综述补证。
