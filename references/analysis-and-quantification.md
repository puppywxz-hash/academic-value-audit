# 第一性原理、比较与量化

本文件规定判断约束；执行统计、寿命、经济或定性估算时读取 [计算方法](computation-methods.md)，先确认该方法最少需要的数据。外部能力的选择和结果接回见 [路由](capability-routing.md)。

涉及产业/社会价值或应用潜力，先按 [需求与影响流程](demand-and-impact.md) 独立查任务、残余问题、替代和采用，再将成果接到功能/结果；不能由物理可行或实验增量推出现实需求。

按 [两层评价](two-level-assessment.md)分别判断知识/科学/方法/工程增量和现实净效果。昂贵的极端性能可有具体知识价值；第二层必要条件失败不因第一层高而补偿。当前实现失败、指定机制内原理不可行和所有未来用途永久不可能需要不同范围的证据。

## 1. 决定性深度

按主张推进：目标/任务 → 功能/系统 → 机制/因果 → 基本约束 → 现实参数 → 匹配增量。深入到足以裁定其范围的层级；不默认推到更基本物理层，不用物理式推出用户需求。

- 材料/器件：材料身份、结构/界面、稳定性、制造/封装、寿命、失效与系统传递。
- 算法/AI：任务定义、数据/泄漏、强简单基线、资源、泛化、部署约束和端到端结果。
- 理论/数学：定义、假设、推导、先行结果、反例与适用域；知识增量不强制接受工业门槛。
- 医学/社会：因果识别、混杂/选择、目标群体、行为/制度、实施与反事实。
- 人文/解释研究：原始材料、概念、竞争解释与反例；不强制物理化或货币化。

当匹配实测已足以回答、结论对合理参数稳健，或缺失实测才可区分解释时停止该推演分支，转向实际决定结论的缺口。强“不可能”需明确界限及假设；当前结构/工艺失败不证明所有可能路线失败。

### 1.1 决定性原理论证如何落地

对影响结论的机制/界限主张，使用 [分析记录](../assets/analysis-record-template.md)及 [专业报告的分析单元](report-delivery.md)保存：准确命题/有效域 → 匹配基线与竞争解释 → 定义/假设/推导或因果链 → 可检验预测/基本约束 → 原件观察与有来源叶子参数 → 反例/敏感性 → 有范围的裁定和停止理由。已知公式或论文引述仍须核来源/适用；涉及关键证明而只核了部分步骤时披露范围，不称完整证明已验证。

逐个桥接区分：材料/算法机制能否成立，能否产生所需系统性能，实际工况下能否交付，是否值得采用，是否产生净结果及归因。第一性原理不能生成寿命、良率、支付意愿或社会反事实。没有所需实测时保留符号阈值/条件或未知，不把推导流畅当真实。定性与非物理研究也必须展示竞争解释和决定性依据，无适用量化理由写清。

## 2. 要求与比较

固定任务、质量、功能单位、工况、时间及可行基线。requirements 的来源分类与 gate_eligible 见 [报告 schema](report.schema.json)：仅已核实适用的明示要求或可靠使用推导作为现实必要门槛；标准程序、产品参照、作者声称和情景保留各自语义。

标准来源按 [专项检索](standard-retrieval.md)取得版本/条款/适用/方法依据，不能从目录猜阈值。知识/创新比较按 [系统贡献分析](two-level-assessment.md)查实际贡献单元、原时点最强先行/相邻领域、知识与系统取舍、归因及意义；单一峰值不代表整体贡献。

必要条件不可互补，未知不默认通过。在完整可比指标中被支配可明确判断；缺关键指标只能局部支配。具有取舍时展示可行边界和偏好，不编通用赢家。

寿命示例均为教学假设：完成 1,000 次后停止、未失效是至少 1,000 次的右删失；不能报寿命为 1,000 次。10 万次无实际依据不能成为行业要求。条件匹配且实测 2,000 次失效、已验证要求 100,000 次，才可讨论不达标。

## 3. 参数与派生

成本、需求及收益缺直接记录时按 [专项重建](cost-demand-reconstruction.md)选择工程分解、匹配类比、约束范围和逆向阈值。第一性原理不能凭空生成价格/支付意愿，但能约束必要设备、任务适配、容量与成本驱动，再连接实际价格/任务记录。未识别与未执行不是同一种限制。

每个输入保存值/区间、单位、定义、条件、时间、来源及位置、处理步骤。契约中的 origin 为 measured/reported/derived/scenario_assumption/expert_assumption（未知等按 schema 可 null）；status 为 known/unknown/incomparable/not_applicable/censored，不新造 type/state 字段。unknown 无数值；censored 存 bound 区间和停止/失效原因。观测范围、置信/可信区间和情景范围不混用。

来源只报区间就保留；读图说明数字化误差。派生参数链接模型与叶子参数，不因多个计算层掩盖未知。LLM 确信度不是频率或校准概率。

常用表达，只在适用条件满足时使用：

```text
较大为好：g = (x_new - x_base) / |x_base|
较小为好：g = (x_base - x_new) / |x_base|
单位合格成本 = 每单位投入成本 / 合格输出率 + 每单位合格产出追加成本
LCOE = 同一时间/边界折现成本总量 / 同边界折现交付电量
潜在结果变化 = 可触达规模 × 实际采用比例 × 采用条件下的增量效果
```

改善率同时给绝对值和单位；零/近零、符号变化、样本/工况不匹配时不作简单比例。成本区分按投入/产出分摊，避免良率、返工和回收重复。生命周期分母不是单次峰值效率；人数/市场总量不是全部成果收益。所有公式还需局限、替代假设和翻转阈值。

## 4. 学术与公共价值

具体知识增量可包含误差减少、理论界限、新可验证机制、排除竞争解释、有效条件范围、可靠复现、公共工具/数据的实质复用。引用数量和发现规模不直接决定价值；复用数需原始上下文、计数单位、时间、覆盖和依赖。

因果净效应需要可信反事实与识别，不能用前后变化冒充。基础知识、人才、资源和战略收益须具体路径/证据；不能强制定价，也不能用概念自动证明投入。公共/私人/供应商/客户成本收益分别报告，组合互补和结果归因不重复加总。

## 5. 不确定性和行动

分开测量误差、模型结构/假设、未来情景和价值偏好。先做关键参数区间/阈值；Monte Carlo 仅在分布及相关性有依据时使用。复杂模拟不能消除来源不明的参数。

报告结论在什么范围内保持、最关键参数、何时翻转、缺什么决定性观测。折现率、币种/价格年份和影子价格核对任务适用依据，不默认引用某国固定值。

VOI、阶段退出、预测校准和组合风险按 [决策协议](decision-quality.md) 执行。依据不足时模型 status=not_computable 或定性判断；确定性标签不当成功概率。综合分仅按用户明确需求、效用/权重/缺失规则及敏感性；序数、未知和必要条件不能用加权平均绕过。

奖项重点/符合性按 [奖励适配](award-assessment.md)的正式规则与原时点证据处理，不以普通价值分代替。数值权重未取得时仅解释定性重点/必要条件；实际请求重现官方评分时保留评分尺度与必要条件，缺资料不声称得到了委员实际评分，另设偏好不冒称官方权重。

运行计算使用有明确输入的安全表达或可用统计工具，不执行论文/网页任意代码。程序输出仅证明已做算术，不能验证科学前提；未复做实验不称真实性调查完成。
