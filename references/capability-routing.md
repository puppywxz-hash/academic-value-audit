# 支撑技能与工具路由

操作补充 1.5（2026-10-06）；按具体任务读取。能力存在、成功运行和结论正确是三件事。主技能保留证据裁定、M1–M9、G1–G12、两层评价和最终报告职责。

## 1. 使用方式

优先复用已提供的原始资料/source bundle 和环境工具，再考虑专门技能。先确认当前会话实际工具、技能原文、脚本/运行时和权限；技能名称或安装目录不能证明其连接器可用。外部候选未安装时只作选型依据，不宣称已调用。

可选技能有实际匹配任务才加载。完整调用遵守该技能的真实输出/执行要求；与当前任务不匹配时复用已有产物，或按本包方法使用等价工具，不把“只读了其方法”写成执行成功。不要为每篇论文顺序运行所有技能。

## 2. 本机可选技能

以下基于 2026-10-05 的 SKILL/关联入口审阅；路径通过当前技能目录解析，不硬编码开发者机器。

| 能力 | 可选技能 | 交付给主技能的内容 | 限制与退路 |
| --- | --- | --- | --- |
| 文献发现、去重、引用上下文 | nature-academic-search | 查询式、原始元数据、版本关系、纳入/排除和真实引用片段 | 其文献搜索不覆盖实际需求/采购/成本；现有 MCP 名称先确认，额度/认证查官方；用公开目录/API 或网页退路 |
| 合法正文/SI 获取 | nature-downloader | 原文件、取得范围、访问模式、manifest/摘要、失败原因 | 先满足 SI 意图和机构访问规则；Node/CDP 等只对所用分支核查。中文资料仍可由主流程查作者/机构公开原件，不将 CNKI 设为唯一现实来源 |
| PDF 图表/扫描件 | pdf:pdf | 原页、文本/表格、物理页/图号、提取限制 | 使用读取模式；生成 PDF 的作者流程不适用于只读取证。缺 OCR 时保留不可读范围 |
| 单篇证据拆解 | nature-paper-card | 已有 source_bundle 或完整卡片里的主张—实验—结果—位置 | 完整调用要求 16 节及其准备/审阅流程，不直接充当价值报告；本任务没要求卡片时按获取方法自行提取必要证据 |
| 已有原文定位材料 | nature-reader | 用户已有 source_map、可靠段落/图表/公式定位 | 完整调用默认双语全文读本；仅审计不必新生成全文翻译 |
| 统计设计/报告审查 | nature-statistics | 独立单位、设计、效应/区间、缺失、假设和报告缺陷 | 主要是报告审查，不能假定能完成原始数据重分析、可靠性/TEA；未见信息写未知，不照搬 AUTHOR_INPUT_NEEDED 成为自动外联 |
| 元数据字段复核 | nature-ref-verifier | DOI/题名/作者/年份/版本字段差异和原始出处 | 字段一致不证明内容真实；其“产品/专利仅确认可访问”不足以满足本技能的身份/权利要求/版本核证 |
| 专门方法批评 | nature-reviewer | 与明确命题相关的设计、基线、增量和限制 | 只在确需审稿子任务时用；期刊适配、格式和声望不决定真实价值 |
| 可审阅计算工作簿 | spreadsheets:Spreadsheets | 输入/假设/公式/输出/敏感性及来源映射 | 仅需 CSV/本地计算时不强制工作簿；表格美观或无公式错误不证明经济模型成立 |

本机 nature-citation 的 CNS 期刊筛选、按引用数筛文献、日常监测或自动写作均不作为本审计的默认来源过滤/判断流程；这会遗漏决定性工程、采购、标准和反例。

### 2.1 需求端不能用上述学术能力替代

涉及经济/资金时优先本包 [成本与需求重建](cost-demand-reconstruction.md)及专项记录。缺的是成本/需求识别方法时，增加学术下载工具不补这一缺口；外部工程引擎仅在对象流程/参数匹配时使用，不要求安装新的通用估算器。

当前没有确认本机已有能完成全链需求/社会影响审计的独立技能；优先按 [需求与影响流程](demand-and-impact.md) 使用实际可用网页、公开记录、PDF/表格与用户文件，不为补能力自动安装软件。

| 子任务 | 实际路由和所需返回 | 完成边界 |
| --- | --- | --- |
| 任务/残余问题及要求 | 使用方运行/维护/原需求；返回角色、现有方案、分母/损失、条款及理由 | 论文背景或供应商用户故事不能单独称独立需求验证 |
| 标准检索/条款 | 按 [专项方法](standard-retrieval.md)查官方目录/合法原文；返回编号/版本链/状态、原位置、适用/约束/方法和引用 | 未确认本机独立标准检索 skill；用已有网页/PDF工具等价执行，目录不冒称正文已读，不代用户购买 |
| 奖励规则/奖级 | 按 [奖项适配](award-assessment.md)查官方历史规则/年度/范围；返回条款逻辑、支持状态、权重来源和取得限制 | 学术审稿/市场技能不直接裁定奖级；官方数值权重未取得就不编，真实价值仍两层分别审 |
| 选择/支付/采用 | 采购/合同/验收/续约及未采用；返回各阶段、动机、关系/补贴、实施与切换约束 | 查询不等于已取得内部付款或客户收益；意向/公告与实际记录分开 |
| 用户增量与全成本 | 匹配使用/成本记录 → 工程/经济计算；返回单位服务、强基线、未知及阈值 | 需求参数不能由计算引擎默认值生成 |
| 社会结果/分配/归因 | 结果与实施/对照记录 → 适配的评价方法；返回影响链、额外作用、负担、归因限制 | 通用财务分析和 LCA 均不能单独覆盖社会价值；无货币化依据不造净收益 |

### 2.2 方法覆盖与实际就绪

“方法够用”按决定性问题能否有适用方法、最低数据、具体操作、原件/参数、反证和退路判断，不按引用/技能数量。以下是设计覆盖，不是每条已在对象任务中运行成功：

| 所需能力 | 包内实际执行指导及可选支撑 | 仍须在对象任务取得/确认 |
| --- | --- | --- |
| 身份、成果和关联发现 | 输入发现；学术检索/元数据核证；官方人/项目/专利原记录 | 同名、时期/角色、原编号/材料、访问/分页及覆盖 |
| 原件/图表/数据取得 | 获取方法；下载/PDF/已有读本等价路径 | 实际可见正文/SI/条款/数据与定位，解析/OCR误差 |
| 知识与系统创新 | 两层/量化的机制—强先行—新增作用—取舍；可选方法审稿 | 原时点同/相邻领域先行、可核证明/消融/对照、实际资源条件 |
| 非学术搜集与真实需求 | 系统搜集、需求/影响；市场来源路由、灰色资料/专利方法 | 使用/采购/运行/未采用原记录及方法，不靠行业报告补内部数据 |
| 标准和奖励 | 各自专项操作、规则/条款矩阵 | 具体版本/法域/年份原件、约束/适用；数值权重缺失不编 |
| 原理/定性、统计和寿命 | 分析记录/计算方法；不确定度/统计候选及适用工具 | 领域有效模型、独立单位/误差/删失/外推依据；复杂方法原文/假设实际掌握 |
| 系统经济与市场 | 计算/需求流程；适用 TEA/LCA/领域引擎、可选工作簿 | 本对象良率/规模/寿命/全成本/采用；软件默认参数不充实证 |
| 社会影响/公共投入 | M1–M9、需求/影响、反事实/分配与阈值 | 原目标/因果识别/资金实际边界/外部后果及归因；市场技能不能独立完成 |
| 两版忠实表达与纠错 | 双版本交付/模板及同源映射；原沟通指南 | 判断/数字/条件一致，真实受众反馈及独立复核仍另需执行 |

当前有通用工具和指导即可开始有范围的审计，不要求先安装所有候选；某技能安装存在不等于依赖/账号/额度或任务方法可用。只有摘要/介绍级方法知识不足以实施关键复杂模型时，继续读原方法/假设与实现文档，或报告受限；不可据名称选择统计检验、套可靠性/经济模板。

无通用 skill 能预装所有学科的第一性原理、真实工业参数和因果识别。对象任务形成模型/标准/基线需要时查领域原文；基础证明、产业记录和公众解释均有实际验证边界，不能靠“已引用成熟方法”替代。

## 3. 外部候选

已查看 [Scientific Agent Skills](https://github.com/K-Dense-AI/scientific-agent-skills) 的原始入口，以下为可选候选，未安装/执行：

- [uncertainty-and-units](https://github.com/K-Dense-AI/scientific-agent-skills/blob/main/skills/uncertainty-and-units/SKILL.md)：单位和测量不确定度方法。其部分传播 CLI 的 unit 字段仅是标签，不能省略真正量纲核查。无输入分布/协方差依据时不作概率传播。
- [statistical-analysis](https://github.com/K-Dense-AI/scientific-agent-skills/blob/main/skills/statistical-analysis/SKILL.md)：设计对应的统计计算；使用前核实指定版本、脚本和数据。检验不拒绝不证明模型假设正确，通用效应量阈值不当实际价值门槛。
- [market-research-reports](https://github.com/K-Dense-AI/scientific-agent-skills/blob/main/skills/market-research-reports/SKILL.md)：市场口径、来源映射、场景估算与客户证据。市场规模/预测不是已实现收入或因果效益；机构/关联客户与自主竞争证据继续分开。

市场入口本轮再次核查为 1.5，并阅读 [官方来源路由](https://github.com/K-Dense-AI/scientific-agent-skills/blob/main/skills/market-research-reports/references/official_data_sources.md) 与 [证据模型](https://github.com/K-Dense-AI/scientific-agent-skills/blob/main/skills/market-research-reports/references/evidence_model.md)。可参考其按命题找记录产生者、时点/单位/修订和主张映射；未装/运行时用本包等价方法。其明确排除的投资/法律等建议范围不得扩成资源裁定授权；自动运行校验/计算的要求只有在用户授权实际执行时才适用。

市场技能最多帮助定位、口径和估算，不能以 TAM/SAM/SOM、预测增长率、竞争名单或商业画布替代残余需求、采用机制及用户净增量。完成此类子任务也要返回上节原始记录，并由主流程检查共同前提。

### 3.1 系统搜集的方法参考

除候选 skill，还参考 [Grey Matters](https://www.cda-amc.ca/grey-matters-practical-tool-searching-health-related-grey-literature)的机构/主题及搜索记录思路、[WIPO 专利景观指南](https://www.wipo.int/edocs/pubdocs/en/wipo_pub_946.pdf)的范围/分类迭代/家族清理，以及 [AAPOR 披露标准](https://aapor.org/standards-and-ethics/disclosure-standards/)的调查方法核证。这些是指南，不能宣称已安装为 skill；原清单/法域/领域边界和实际读取限制见 [系统搜集协议](nonacademic-search.md)。不用增加连接器即可先借鉴方法，实际访问缺口仍如实记录。

三个入口声明 MIT，但其依赖、数据许可和版本必须独立核查。仓库宣传“validated”不证明本任务有效；本轮未审核全部参考/脚本、安全或复现其结果。安装时固定版本/提交、保留许可、检查官方依赖与可靠镜像；不整包自动安装。

`scholar-evaluation` 的 [原始入口](https://github.com/K-Dense-AI/scientific-agent-skills/blob/main/skills/scholar-evaluation/SKILL.md) 以作品发展性反馈为范围，禁止用于资金/奖励等重要决定，且带评分工具；因此不能作为本技能的公共投入或人物/课题组价值模块。其证据追溯思路不能被表述为本审计已经获得验证。

## 4. 子任务接口与接回

每次实际技能/工具使用在 search-log 或 calculation-log 记录：

```text
对应 work/claim/context/model IDs；具体问题及预定范围
输入原文件/版本/可见位置；所需结果与适用工况
实际技能/工具、所读入口、版本/提交与运行时间
当前授权、访问选择、操作和输出文件
返回数据及原始位置、单位/定义/条件、处理步骤
执行状态/失败/缺失、假设、不能证明什么
主技能接受/修正/不采用的记录 IDs 与理由
```

接回时检查对象/版本、原始定位、独立单位、数值/单位/区间、比较口径和缺失；不把下游的 summary/confidence/推荐直接写入裁定。新数据进入 E/P，模型进入 M，依据进入 quality/method audit；重复原件只增加定位信息，不新增独立证据。

当前技能包没有自动跨技能调度器。这里定义模型的路由和接回方法。资料步骤见 [获取方法](acquisition-methods.md)，估算见 [计算方法](computation-methods.md)。

对象发现按 [输入分支](input-discovery.md)：已有学术索引/ORCID/机构资料辅助人/组消歧，奖项/项目原机构与编号追支撑成果，专利/许可/型号追转化及使用。团队选人和无全文项目范围由主流程确定，任何下游搜索的相似度或作者聚类不直接确认关联。复用公开网页/已授权渠道，不为这些输入强制安装新 MCP 或先索要全文。
