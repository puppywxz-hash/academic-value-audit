# 价值立场、证据综合与决策质量协议

协议版本：1.0｜适用于设计/报告 1.4、证据质量协议 1.2｜2026-10-05。

本协议正式采用用户认可的方法补充 M1–M9。规则是本项目的领域适配；参考框架及取得范围见 [方法来源](method-sources.md)。领域共识或官方指南本身不能证明某项研究的需求、效益或投入合理。

## 1. 适用与记录

正式评价实际价值时读取本协议。输入仍可以只有题名、材料或人/组线索，入口自行补齐评价范围和默认设置，不要求用户先填表。

每个评价情境 `context_id` 对 M1–M9 各作一条适用审查：`applicable / not_applicable / undetermined`，配 `completed / partial / unassessed / not_applicable`、范围、依据、具体记录 ID 和对措辞的影响。数组长度和非空理由不证明完成。未知不能为绕过检查而设为不适用；实质缺口限制依赖它的判断，其他判断继续处理。

M1 与 M9 对所有价值评价适用；M2 对影响关键判断的证据集合适用，即使只有一个证明或实验。M3 在公共投入/回报主张适用；M4 在预测或承诺兑现评价适用；M5 在建议验证/研究时适用；M6 在涉及阶段投入或下一步行动时适用；M7 在系列、组或组合总体结论时适用；M8 在产业/社会后果主张时适用。纯基础工作不强制产业模型。

一个情境保存相同问题、范围、时点与评价视角下的判断。目标、行动或时间视角不同且可能改变结论时另建情境，不把事前/事后证据混为同一评价。G11/G12 在每个关键判断的放行中落实；只有原始观察、没有价值主张的局部判断可相关不适用，但须说明。

## 2. M1：评价问题、目标与价值立场

`decision_contexts` 记录 question、scope、judgment_ids、时间视角、评价立场、目标表述/出处、受益和负担主体、可比较行动、资源边界、偏好及目标核查。

- 先区分事实、知识增量、实际影响和资源配置问题。评价者不得把用户或研究圈的预期答案写成事实。
- 目标来源区分已验证需求、知识缺口、用户优先事项、规范选择、暂定或未知。课题使命、政策目录、奖项评审和圈内背景相互引用不能单独验证目标。
- 向上追问重要目标的依据；不把单篇审计扩成无限制全国预算评价。若结论依赖更上层前提，报告其未知及失效影响。
- 默认各价值维度分别评价，不提供通用权重。即使事实相同，主体、时间和风险偏好不同也可能改变选择；分别列出，不用争议回避可靠反证。
- 单纯贡献审计的行动可为 `assess_only`，资源/决策主体未知不阻断已有事实。只有用户要求单一排序、具体资金建议而偏好决定结果时集中询问缺失信息。

## 3. M2：证据集合的确定性

逐条质量检查之后，在 `evidence_syntheses` 按同一终点、比较、对象、工况、尺度与时点综合证据。

1. 保存纳入/排除材料及理由、原始单元和依赖；独立再分析与新增观察分开。
2. 说明一致性、可解释的异质性、未解释冲突和缺失。不可比条件不求平均；不能删掉不利结果以制造一致。
3. 分项解释方法偏倚、结果一致性、直接性、精度和未报告结果；关联既有证据质量记录。
4. 记录 `high / moderate / low / very_low / not_assessable` 及理由，这是所述命题/效果范围的证据确定性，不是论文价值、成功概率或投资建议等级。
5. 标明方法 `adapted_claim_specific / full_grade / qualitative`。默认适配通用维度，不套临床研究起始等级。完整 GRADE 只有任务适合、实际按该方法执行时采用，不能借名称宣称认证。

单个可靠反例或形式证明可充分支持相应命题。高确定性的微小改进仍可能实际价值有限；材料机制确定不证明系统收益确定。缺证与反证分别裁定，不以“结论不确定”自动推荐更多同类实验。

## 4. M3：公共资金的额外作用

适用时 `funding_reviews` 保存资金来源/实际范围、无该资助的反事实、其他资助可能性、替代用途、知识外溢/开放获取路径、私人/公共收益边界、成本记录和归因结论。

- 核实批准、拨付和支出；私人资本、国资股权、科研经费、采购和补贴分别记录。
- 询问资金增加、提前、共享或改变了什么。不能把本来可能发生的商业支出全部算作公共资助新增收益；也不能假定私人资金必然替代公共资金。
- 公司收入、财政转移、工资与其他支出不能直接相加为社会净收益。各方财务流与实际资源/福利变化分开，避免重复计算。
- 公共物品、知识外溢和公平目标是待论证的理由。明确受益路径、实际新增、规模和机会成本，不用“战略”“培养人才”自动补值。
- 有可信识别才报告因果净效应；否则限定贡献论证或未知。基础知识、公共工具和反证可定性举证，不强制货币化。

## 5. M4：承诺兑现与预测校准

`forecast_reviews` 保存原承诺、提出时点、期限和口径，逐条后续结果、测量状态与出处，再说明可比参考类别、固定分母、观察/删失及预测误差。

- 必须比较相同任务、路线/起点阶段、功能单位、价格年份、规模和资助条件。期限未到、访问不到、真实失败和延迟分开。
- 参考类别与筛选条件按预测当时可知信息定义；不能用事后赢家/输家反向挑选类别。对历史评价仅用当时能获得的证据。
- 数值误差使用同单位实测与原预测；比例基准为零或不具有比例意义时不除。兑现率需可信固定分母、终点和随访。
- 有可迁移历史误差时校准成本、收益或时间预测；没有时保留 unavailable、情景和翻转阈值。不能套英国项目的固定调整百分比，或从示范案例编成功率。
- 第一方试点、融资、授权和发货先作为事件保存，持续运行、复购、净收益另证。

## 6. M5/M6：下一次验证、分阶段行动与退出

每个推荐验证在 `research_options` 保存决定性问题/参数、竞争解释、结果到行动的映射、验证成本、延误/实施影响、信息价值方法、里程碑和停止/转向/扩展条件。

```text
EVSI = E_D[max_a E(U(a, θ) | D)] - max_a E(U(a, θ))
验证的预期净价值 = EVSI - 尚未纳入模型的取证、延误和实施成本
```

`a` 是可行行动，`θ` 是未知状态，`D` 是新研究的数据；效用 U 的立场、单位和时间须说明。计算引用主报告的参数/模型 ID；概率来源、参数依赖、模型结构、数据生成过程、可影响人数/设备、有效期限与采用条件须有依据并作敏感性分析。

没有可靠分布或效用模型时用阈值/定性行动映射，不将模型确信度当概率，不输出假精确 VOI。降低熵与改善决定的效用分别说明。纯基础研究可以有知识增量，VOI 不覆盖其全部价值。

- 预先写明什么结果支持继续、改变路线、扩展、延后或停止，以及可避免支出与不可撤销/退出成本。
- 里程碑应检验关键假设；论文数、设备数量或再一次样品记录不能代替价值验证。
- 比较相同目标的行动与资源规模，包括不投入、成熟替代及小规模验证。证据相同可以支持有限验证而不足以支持不可撤销扩张。
- 不因沉没成本续投，不因缺证自动要求新研究。验证若不改变行动，仍需具体知识/公共资源增量才能支持推荐。
- 失败产生的认识要具体举证。事前验证价值、已取得知识和原项目合理性分别判断。
- 依据未来信息调整规模/退出的选择价值与 VOI 可能重叠，不能简单相加。

## 7. M7：组合的边际贡献与共同风险

对系列、组或组合的总体判断，`portfolio_reviews` 保存成员与时期、已有工作组合、新增工作带来的增量、必要互补/有效复现、重复效益、共同前提和关联风险。

- 相对已有组合比较新项目，不能给每个组件分配完整最终收益；必要配套按其实际角色评价。
- 区分新增路线、解决不同瓶颈、有效复现/公共维护，与不改变认识或决定的重复指标展示。
- 多团队共享未验证需求/成本前提会集中风险；用依赖和前提证据说明，不能由同领域身份推定控制或操纵。
- 没有可校准联合概率时仅作结构/情景判断，不套投资组合公式猜科研成功率。
- 整组评价需与发现/深读覆盖匹配；不静默挑代表作代替全部已纳入工作，不将单篇结果推广到所有成员。

## 8. M8：收益分配、完整后果与实现条件

`impact_reviews` 固定任务、合格功能单位、时长和真实基线，保存各主体的效益/成本/风险、生命周期边界、分配、可负担性、组织/监管/维护条件及成熟度证据。

- 功能单位必须包含真实服务质量。光伏可按特定任务的交付电量比较；LED 先确定照明/显示等目标，再定单位，不把材料指标当所有器件目标。
- 生产、使用、替换和处置的负担逐项核查，排除项和未知项明确；避免把成本/风险转移给别的群体或阶段后称全面改善。
- 单位成本有效、总体预算能否承受、用户能否使用是不同问题。实际采用需人员、训练、集成、维护、监管及激励条件，不能只报器件性能。
- 组件技术阶段、目标系统验证、制造/交付、组织准备和实际经济性分别记录；序数阶段不求平均，不合成价值等级。
- 各主体的成本收益不能在不同范围重复相加；无数据保留未知，不从地区/身份推断需求和偏好。

## 9. M9：评价治理、纠错与更新

`governance` 保存用户待核假说、评价立场与已知关联、评价方法限制、材料纠错、回应及采纳理由、版本/策略变更和受影响记录。

- 对正负主张执行相同要求。用户或评价者认为某技术失败，是待核假说；不能作为测试该方法是否正确的预设标签。
- 已核实财务和学术立场关系影响风险检查，不自动定真假。未知关系保留未知；模型不宣称自己能保证无偏。
- 提供可复核材料和纠错接口；受评者提供的解释仍按证据处理，未回应不证明结论。未经明确授权不联系人员、发送报告、索取秘密或公布评价。
- 更正原数据、对象身份、成本或方法时保留旧版，记录依据和受影响判断/模型，重新计算和放行；没有变化不伪造回应。
- 定期依据真实使用检查指标是否诱导包装、忽略本地知识/长期探索/必要复现；版本调整不能追溯性地掩盖旧结论。

## 10. 放行、数据与迁移

报告 1.4 必填 `method_audit`，使用 [决策质量契约](decision-quality.schema.json)。每条关键判断的证据质量审查关联 context/check/synthesis ID。

- **G11**：按适用终点/工况完成证据集合综合，依赖、异质性、缺失和确定性足以支持拟议措辞。未通过时拆分条件、限定或未决。
- **G12**：评价立场、目标前提及适用 M1–M9 实质处理，行动建议的规模、成本和不确定性与依据相称，评价过程及限制可核查。未通过时限定到已知贡献，暂缓该规模/强度的建议，或仅给条件。

M1–M9 完成不意味着所有实体确定或正价值。适用检查 partial 可以支持限定结论；不能因此放行未获证实的强建议。每个 check 的范围/关联需实际覆盖本 judgment/context，不能用另一项目完成记录替代。

1.3/质量 1.1 报告迁移需补建 context、M1–M9 适用审查、相应记录、G11/G12 和新的放行关联，必要时降低措辞；不能只改版本或全部填不适用。原证据/模型若仍有效可复用。旧讨论文件保留其历史时点，当前规则以正式规范为准。

## 11. 方法原始来源及适配边界

- [Cochrane 第 14 章](https://www.cochrane.org/authors/handbooks-and-manuals/handbook/current/chapter-14)：具体结果的证据集合确定性。临床起始等级不自动移植。
- [EtD 原始论文](https://link.springer.com/article/10.1186/s12961-018-0320-2)、[HTA 共识定义](https://doi.org/10.1017/S0266462320000215)：证据、偏好、可行性和多方后果分开；卫生阈值不直接移植。
- [DOE TEA/LCA](https://www.energy.gov/cmei/ito/life-cycle-assessment-and-techno-economic-analysis-training)、[ISO 14040 目录](https://www.iso.org/standard/37456.html)：功能单位与生命周期结构；未获取标准全文不声明条款合规。
- [Green Book 2026](https://www.gov.uk/government/publications/the-green-book-appraisal-and-evaluation-in-central-government/the-green-book-2026)、[Magenta Book](https://www.gov.uk/government/publications/the-magenta-book/magenta-book-central-government-guidance-on-evaluation-html)：方案比较、因果链和公共投入；目标本身继续核查，本地财政参数另证。
- [VOI 方法报告](https://pmc.ncbi.nlm.nih.gov/articles/PMC7373630/)：决策相关信息及模型前提；不是所有基础知识定价方法。
- [莱顿官网全文入口](https://www.leidenmanifesto.org/translations.html)、[DORA](https://sfdora.org/read/)、[CoARA](https://www.coara.org/agreement/the-agreement-full-text/)：成果评价、透明纠错和指标后果；同行共识仍需实证。
- [GAO TRA](https://www.gao.gov/products/gao-20-48g)：成熟度/系统风险参考，本次仅核对官方摘要，不宣称完整审阅或商业价值等级。
