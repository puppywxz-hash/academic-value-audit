# 计算能力与任务优势（2.0）

适用：量子/光学/模拟计算、专用加速器及计算优势/生产力主张。状态：初版，2026-10-08以GBS定向试用；未经独立专家审定。技能2.0，报告1.4。

## 核心区分

区分通用可编程、特定模型参数可调、特定分布采样、解决真实任务和商业交付。模式/点击数、物理量子比特、逻辑量子比特、可执行电路深度不可互换。“通用”也不代表所有任务都有加速。

列任务族、输入表示、规模、输出精度、成功率、可验证性与现实需求。评价单装置时核实际操作集；路线理论潜力需与装置具体贡献分开。

## 最小模型

T_total = T_encode + T_prepare + T_control + K*T_run + T_read + T_post + T_verify。

K是达到约定质量/成功率的重复次数；独立、定成功率s的试验达到至少一次成功概率q，K≥log(1-q)/log(1-s)。相关采样/迭代变分布不可直接套用。校准/编译摊销按真实工作负载处理。

若同一任务中可加速部分原占f、局部提速S、其余不变且不计新增开销，总提速≤1/[(1-f)+f/S]。这是条件上界；没有同任务映射时f未定义，不可将采样倍数硬代入。成本另含设施年化、运行维护、经典协处理及合格吞吐。

## 强比较与迁移

- 科学采样：同分布、误差/噪声及精度口径；通过若干统计验证不等于全分布接近。
- 终端任务：比较最佳适用算法及CPU/GPU/专用硬件，不要求经典机模拟实验装置，除非模拟本身就是任务。对齐输出质量、资源、预处理和成功率。
- 当前到未来：列源、门/测量、前馈、存储/延迟、纠错、控制的必要资源与现有实现；识别哪些可复用、哪些需新增。理论通用光子路线不能直接为某台GBS背书。
- 当时与当前算法基线分别评价。新算法可削弱当前优势，不能倒推原实验没有科学贡献。

## GBS专有争点

调查专业博客及评论里的应用/验证争论，按[社区调查](../practitioner-debate.md)核查。可用入口：Aaronson的[2019应用批评](https://scottaaronson.blog/?p=4447)和[2020九章讨论](https://scottaaronson.blog/?p=5122)。日期、被评论对象和作者关系须保留；讨论中的原始反例可检查，成本转述不能直接作项目实支。

随机复矩阵采样与部分应用的结构化/非负矩阵不是同一实例类。核应用映射是否保留困难性、后选择开销及优质解概率。概率难计算不证明解决用户任务必须进行同样计算。

特别查：GBS是否只改善经典局部搜索的初始化，比较的是均匀随机还是强经典启发式；把图编码成分布后，读出/区分是否仍承载原难题。保持信息或产生难模拟分布不自动解决任务。非通用性只否定通用用途，专用加速仍需独立检验。

损耗/可区分性/探测噪声既改变输出，也可能降低模拟难度。验证相关函数不排除所有高效经典算法；不同代装置的模拟结果不自动覆盖目标输入。

## 原始方法入口

- [GBS原实验](https://arxiv.org/abs/2012.01625)：实际结构与原基准。
- [图问题经典比较](https://doi.org/10.1103/PRXQuantum.5.020341)：非负图矩阵任务；非一般GBS模拟器，同时讨论潜在优势条件。
- [有损GBS模拟](https://arxiv.org/abs/2306.03709)：须核具体装置、误差和运行条件，不由摘要断言全路线可模拟。
- [KLM理论](https://arxiv.org/abs/quant-ph/0006088)：通用光学的资源条件，不等同现有装置经济升级。

每次审计核适用性和新基线。方法模块不预设路线价值。
