# 半导体器件的制造成熟度与跨尺度迁移

2.0增加的执行要求：先按[研究主流程](../research-engine.md)说明哪个材料/工艺缺陷通过什么机制限制电路，再用下述清单取证；清单本身不算解释。CNT电子类型比例、手性/直径分布、器件电学失效率、芯片良率是不同变量，不得直接互代。大电流烧蚀只是部分历史路线，须主动核溶液分选、转移、低温沉积和设计容错的实际进步。

特别反证入口：[Bishop等2020商业制造设施原研究](https://www.nature.com/articles/s41928-020-0419-7)报告200 mm晶圆上利用现有设备制作CNFET；它反驳“所有路线都不能进入硅制造设施”，不证明先进节点量产性能/良率。已有[2019微处理器](https://www.nature.com/articles/s41586-019-1493-8)及[2024 TPU](https://www.nature.com/articles/s41928-024-01211-2)的系统结果也须保留，并区分实验尺度与系统模拟。不能用陈旧的单一路线困难代表当前全领域。

建议将规模推导进一步转为决策：若Y=(1-p)^N只是独立不可修复致命缺陷情景，p必须是电路级有效失效概率；评估材料纯度需增加每器件管数、几何/电学网络、相关性和容错映射。单位合格芯片成本可用(C_wafer/n_gross)/Y+C_test+ C_package构建，在同年度/配置下核工作量与良率；此式不自行提供任何实际单价。下一步支持应针对会改变系统PPA、可靠性或合格成本的瓶颈，不能仅以单管记录作为扩产依据。

本模块用于审计材料/器件研究将性能主张延伸到阵列、集成电路、制造平台或商业产品的证据链。与 [功能必要性与能力迁移](../functional-necessity-and-transfer.md)、[需求与影响](../demand-and-impact.md)、[分析与量化](../analysis-and-quantification.md) 配合使用；仍由核心技能裁定事实、学术增量、实际价值和公共投入，不新增评分或 JSON 字段。

## 1. 先限定技术路线和原主张

把实际主张拆成一个或多个明确终点：单器件物理/性能、阵列、简单电路、专用器件或射频功能、逻辑/存储芯片、现有 CMOS 的延伸/替代、异质或后端集成、量产产品。区分作者原文、项目承诺、媒体/机构扩展表述、审计者提出的候选场景；只用相称证据评价相应主张。

不能把“CNT”“新型半导体”“晶圆级”“CMOS-compatible”“计算机”等标签作为完整技术能力。确认器件拓扑、材料形态、分选/生长/转移方法、工艺顺序、目标节点/功能、晶圆/批次覆盖及实际展示系统。材料名称相同不代表工艺、成本或产品能力可互换。

## 2. 沿制造链逐层核查

按目标路线选择适用环节，记录证据达到的实际尺度。没有做的环节写未展示/未取得，不自动判该路线不可能；但不得让低层证据为高层应用背书。

| 层级 | 需要审查的量或过程 | 典型跨层误推 |
| --- | --- | --- |
| 材料及批次 | 半导体/金属比例、直径/带隙分布、长度、纯度测量的检出限/样本量、批次差异、残留/掺杂稳定性 | 单根优质管/单批高纯样品代表可稳定供料 |
| 阵列及定位 | 管密度与间距、方向/位置、束化、缺失、交叉、材料利用率、面积和晶圆/批次覆盖 | 显微照片中的均匀局部阵列等于全晶圆均匀阵列 |
| 器件与接口 | 接触电阻/长度、栅控、漏电/开关比、阈值分布、介质成核和界面陷阱、迟滞、击穿、稳定性 | 峰值电流/迁移率代替分布、互补操作或长期可靠性 |
| 工艺整合 | 生长/转移/分选步骤、温度预算、污染规范、溶剂/聚合物残留、光刻/刻蚀、对准、n/p 器件形成、通孔/互连及后端工艺 | 作者称“CMOS compatible”就等于兼容某条现有量产线、无需新增步骤或重新认证 |
| 电路和芯片 | 实际功能、器件数量与拓扑、缺陷容忍/修复、片上互连、测试覆盖、面积、功耗、速度、与同任务强基线的匹配测量 | 少量晶体管可运行程序等于可规模化通用 CPU；单项 fT/fmax 等于系统频率/能效优势 |
| 制造与应用 | 晶圆/批次/多批统计、良率、变异、寿命/失效、产能/周期、可重复制造、封装和系统成本、客户任务/产品资格 | 实验室规模可制造等于高量产成熟；研发试点/设备采购等于终端产品需求 |

至少对每项关键数据保留样本数、分母、面积/器件数、测试/估算/模拟状态、流程和测量不确定度。凡比较“均一”“晶圆级”“可扩展”或“高良率”，追问定义与统计单位；不得用器件个数替代良率分布，也不得用晶圆直径替代全片可用器件比例。

## 3. 把门槛变成有资格的证据命题

每个可能决定价值的要求写成“目标任务/工艺—要求数值或定性条件—来源及版本—适用理由—测量定义—是否为 gate_eligible—该工作匹配结果”。按核心报告 schema 现有字段记录；不创建新枚举。

门槛来源按其实际证明能力使用：

- **正式标准/认证规则/用户验收文件**：核版本、法域/产品类别、条件、测试方法和必要性。一个测试方法标准不自动规定所有产品必须达到某个耐久数值。
- **晶圆厂/设备厂公开工艺窗口、可靠性规范或明确客户规格**：只有确认对象、节点、流程和用途匹配，才可作为具体路线要求。厂商宣传页不能代替完整工艺或验收文件。
- **行业路线图（如 IEEE IRDS/历史 ITRS）**：可用于识别产业关注的瓶颈、时间尺度和路线图目标；其目标不是对所有器件/节点都适用的法定/通用淘汰线，也不证明需求、商业采用或该路线必然成功。记录版次、章节、目标路线和原文措辞。
- **独立产品/用户/采购/生产记录**：用于核真实任务、规格、付费、采用及可交付性。科研设备采购只能支持对应研究设备交易，不能代替逻辑芯片或终端产品市场证据。
- **领域论文或专家判断**：适合定位机制、候选门槛和分歧；若来自被审同一研究网络、共用数据/模型或反复互引，应识别依赖链，不能按论文篇数计算独立验证。

如果暂时没有合格现实门槛，保留为路线图目标、作者目标或情景假设，不伪装为当前产业硬指标。要判断不达标，测试方法、器件结构、环境、规模和时间应与要求匹配；否则结论只能限定为局部性能差异或证据未对齐。

## 4. 半导体与 CNT 的路线特定检查

对碳纳米管晶体管，至少按所声称任务审查以下问题；不是每篇基础器件论文都要完成整张清单，但凡向逻辑量产外推，未处理的关键制造门槛必须明确。

1. **电子类型和结构分布**：半导体管比例、金属管造成漏电/关断失败的机制、直径/带隙分布如何进入阈值和性能变异。不要断言所有器件都必须完全相同的 `(n,m)` 手性；要求取决于器件/阵列目标。
2. **分选或生长方案**：电烧蚀/电击穿、溶液/聚合物分选、选择性生长、转移等逐路线查纯度、产率、管长、材料损伤、残留物、定位能力、重复批次和兼容步骤。某一路线的困难不能证明没有其它路线；展示高纯结果也不自动证明其能在目标芯片规模内保持良率。
3. **阵列**：核取向、密度、pitch、束化/交叉、晶圆均匀性与管间电流分担。判断示范是否达到该目标节点/功能的通道密度和统计均匀性，不拿“阵列”一词作规模结论。
4. **接触与栅介质**：查接触电阻、接触几何缩放、介质成核/界面陷阱、迟滞/漏电及热/偏压可靠性；把这些影响连接到电路的阈值、静态功耗、噪声裕量与制造变异。
5. **CMOS 流程**：对直接生长、低温转移、后端集成等独立流程画顺序图；逐项与目标生产线的热预算、金属/催化剂污染规则、溶剂/残留、对准、互连和既有器件保护条件对照。“CMOS compatible”仅按论文展示的具体层/流程和受测功能解释。
6. **目标系统及替代**：逻辑替代比较同节点/同任务 CMOS 的 PPA（性能、功耗、面积）和可靠性/设计生态；射频用途比较同频段、线性度、噪声、输出、集成度和成本相称的 RF-CMOS/GaAs 等；柔性或传感路线单独与实际任务的氧化物 TFT、有机/硅器件、传统传感器等比较。不得用一个用途的证据替另一个用途背书。

路线图示例的正确用法：[IRDS 2023 Beyond CMOS](https://irds.ieee.org/images/files/pdf/2023/2023IRDS_BC.pdf) 讨论过半导体管纯度、相对均一的直径分布、紧密有序且 pitch 一致的阵列，也列接触效应、变异性和栅介质界面等问题；其中 99.9999% 半导体管纯度和 >125 CNT/µm 是路线图目标语境中的目标值，不是所有 CNT 产品的普遍要求。该文件同时记录持续进步、无已知根本障碍。引用它时既不能省略未解瓶颈，也不能省略路线图的正向判断；它不证明已达到量产条件或存在市场需求。

## 5. 可用的规模推导和停止条件

第一性原理可用于解释制造指标为什么影响终端功能，也可推导需要达到的阈值；它不能自行生成实际纯度、工艺能力、产线容忍度、良率、客户需求或成本。

例如，在每个器件缺陷相互独立、无冗余且任何一个缺陷都会使芯片失败的简化模型中，含 (N) 个器件、单器件缺陷率为 (p) 的全良概率为：

\[
Y=(1-p)^N,\qquad p_{max}=1-Y_{target}^{1/N}.
\]

该关系可展示从小电路到大芯片的规模压力。它不是实际良率模型：真实失效可能相关、可筛除、可冗余修复，且“器件缺陷”的定义随电路而变。只有给出 N、目标良率、失效机制和架构假设，才计算情景；做独立性/修复率敏感性，不把推导结果说成实测工艺能力。CNT 阵列中的金属管比例也不能不经网络拓扑/通道数/电学测量模型就直接代入为器件缺陷率。

完成该应用分支前，至少要有：

- 原主张及其规模/成熟度措辞；
- 实际展示到的最深层级，以及尚未跨过的决定性工艺/系统门；
- 至少一个同任务强替代或说明为什么不适用；
- 关键参数的来源、定义、测量范围与不确定性；
- 证据支持/反证/无法判断的分别裁定，以及最可能改变结论的下一项资料或实验。

未发现终端产品/市场命中时，还须遵从[全球多来源检索与分层零值裁定](../research-saturation-and-zero-rule.md)：先做全球学术/专利/公司/产品/采购候选发现，再具体列出已查的行业/任务、地区/语言/渠道和命中阶段，并把新发现的公司、专利、许可、产品、采购、实际使用、停供和失败线索追到可分类。完成适用调查仍无有效结果证据时，明确列出所查行业/任务并说明该主张不能支持本轮扩大投入；机制反证与计量零值另按来源判断协议论证。不得以“没穷尽所有市场主体”或未证实潜力回避结论，也不得因此只查少数案例。确认学术或器件进步，也不可写成量产优势已建立；限定应用的判断不抹去独立学术贡献，也不外推到已分别证明其它结果的应用。

## 7. 校准跨尺度表述的原始资料例

以下资料用于说明“研究演示必须按实际层级陈述”，不是 CNT 全领域价值结论，也不能代替每次审计重新取得原文/SI和强先行比较。

- Shulaker et al., “Carbon nanotube computer,” *Nature* 501, 526–530 (2013), [DOI: 10.1038/nature12502](https://www.nature.com/articles/nature12502)。论文页面报告 178 个晶体管的简单计算机，可运行简单操作系统及若干任务。它支持当时的电路级里程碑，不等于大规模芯片、现代通用 CPU 竞争力或量产。
- Rutherglen et al., “Wafer-scalable, aligned carbon nanotube transistors operating at frequencies of over 100 GHz,” *Nature Electronics* 2, 530–539 (2019), [DOI: 10.1038/s41928-019-0326-y](https://www.nature.com/articles/s41928-019-0326-y)。论文页面报告 110 nm 栅长的 wafer-scalable 射频器件及部分器件超过 100 GHz 的射频指标。它支持特定器件/射频演示，不能单独证明全片量产良率、通用逻辑替代或持续市场需求。
- [IEEE IRDS 2023 Beyond CMOS, §3.2.1](https://irds.ieee.org/images/files/pdf/2023/2023IRDS_BC.pdf)。此处用于定位 CNT 逻辑路线的目标和仍在推进的材料/接触/变异/栅介质问题；路线图目标不自动成为法定/客户门槛，路线图也不等于市场验证。

本方法设计阶段读了 IRDS 原件相关章节，以及两篇论文的出版商页面/摘要信息；未在本轮逐篇取得并精读上述论文全文/SI、数据、工艺附录或后续独立采用资料。若把其中任何一篇作为审计对象，应按实际取得范围重新记录，不能继承本段充当完整原文核查。
