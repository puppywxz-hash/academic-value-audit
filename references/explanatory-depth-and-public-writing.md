# 成果解剖、解释深度与大众长文（2.2）

生成专业版与大众版前必读。读者默认具备一般科学常识，但没有受审领域的训练。完整报告应使其能说明成果究竟是什么、创新发生在哪一层、为什么出现瓶颈、强替代怎样工作，以及判断如何影响经费。大众版默认是充分展开的通俗解释，不能自动变成专业版摘要。用户另要求短版时，才按所需长度调整。

## 1. 先解剖对象，再写创新评价

从实际读到的原文、方法、图表、SI或其它原始记录建立“对象解剖”。不能靠标题、摘要或创新标签补齐技术细节。每项标证据位置；不明且会改变解释的步骤返回取证。

- **实体/成果形式：** 实际制成、证明、测得或交付的是什么？一段材料、单器件、阵列、算法、实验平台、临床证据或其它成果？不要把局部对象称作整套产品。
- **结构与流程：** 输入、关键部件或论证步骤怎样组织，怎样制造/准备、运行和读出，最后得到什么输出？哪些环节论文没有实现？
- **新增部分：** 相对最近强先行，具体增加或改变了什么材料、几何、工艺、操作、推理或测量？哪些是已有部件/原理，哪些是新组合，新组合为何有作用？
- **作用机制：** 新增部分怎样改变局部变量，该变量怎样影响实验结果？给定义、关系、有效域，解释图/曲线展示的实际行为。
- **证明到哪一步：** 实验/证明如何区分关键解释，比较对象是什么，测量尺度/样本/工况如何？未经展示的后续能力不能补进对象介绍。

创新讲解先让读者看懂“东西和变化”，再评价重要性。“首次实现X”“建立平台”“提出新机制”必须随后解释X的实体、改变方式及证据，不能让标签替代介绍。

## 2. 专业版的解释性正文

除决策摘要外，以下内容必须在正文得到充分展开。可按论证合并章节，不必机械编号。

**领域背景有来由。** 讲清知识问题/使用任务为什么产生，既有路线如何完成它、哪一步仍受限；区分发表时与当前图景。只保留会影响贡献或投入判断的历史转折，并解释转折原因。论文数量、奖项和市场规模不能替代领域状态。

领域背景必须解释实际工作关系，不能只报“领域很热/替代存在/性能更高”。至少讲透一个决定评价的具体链条：关键元件/步骤各自负责什么；哪项读数决定下游结果；它怎样满足或未满足目标任务；竞争路线把困难放在哪里。详见[领域理解与因果解释](field-understanding-and-causal-explanation.md)。

**成果本体可复述。** 根据对象解剖，用连续叙述介绍结构、准备/制造、工作过程、输出和尺度。第一次出现决定性术语时解释它是什么、在链条里做什么；符号、器件名、缩写和参数不能代替工作原理。论文关键图表应有文字解释，必要时自画注明来源的流程/结构示意。

**创新可定位。** 逐一讲清最近先行已经会做什么、本工作新增哪一步、为何此前困难、它用何种方式解决、哪些仍未改变。既比较核心原理，也比较工艺组合与实际可运行能力；不能只列相似论文表或堆“首创”。

**替代方案同样讲透。** 对主导判断的最强替代，介绍它怎样实现同任务、把困难放在哪里、付出什么代价、适用条件是什么。并解释为什么选它作比较。仅列“CMOS/锂电/经典算法/岛桥更成熟”不算完成，也不能用未来方案推翻当年的贡献。

**瓶颈有因果深度。** 写出“限制的机制或证据 → 对合格输出的损失 → 规模/工况如何放大 → 补救需要什么 → 相对替代的后果 → 本输入改变了多少”。按问题说明相互作用和主次；泛写稳定性、成本、集成、需求有挑战不够。量化有依据时给参数和量级，没有时给可检验关系和已知事实，不编数填充。

**资金结论有完整推导。** 说明买到的知识/能力是什么、为何值得或不值得这阶段投入、替代研究/工程行动是什么，以及哪项证据改变选择。不给标题或品牌替代贡献权重；只能在证据充分时明确写“值得优先支持”。

## 3. 大众版：详细直白的解释性长文

借鉴用户提供的钠电文章的通用组织特点：开头亮出判断，从最初合理的期待讲起，逐层追到材料/器件/制造/系统/竞争关系，再回到投入选择。用自己的语言组织，不能复制作者句子、口头禅或把其所有技术解释直接当事实。

建议的叙述推进，可按对象调整：

1. **先告诉读者判断及主因。** 明确评价哪项工作、哪类用途或资金。随后解释，不用结论口号反复铺满正文。
2. **为什么当初让人期待？** 把直观优势、原问题和研究动机讲明白；肯定动机里合理的部分，再检验期待中的每个因果跳步。
3. **这个工作到底做了什么？** 把结构/操作拆开讲，解释主要部件如何配合、作者改了哪里、实验结果意味着什么。第一次出现专业词用日常语言释义，再给准确术语。
4. **现实任务已经怎么做？** 详细说明同任务最强替代的原理、工程取舍与实际证据。读者应能理解为什么新办法必须和它比较，而不只是认可“已有替代”。
5. **优势为什么兑现或中断？** 顺着核心因果链讲透关键障碍：改善哪里、剩下哪里、补救要付出什么。拆开材料指标、器件表现、整机输出、用户收益与市场兑现，解释中间差别。数量级注明比较分母、时间和工况；算例标为算例。
6. **这留下什么科学贡献，钱应投向哪里？** 给自己的有据判断，把知识价值和具体应用作用接回目标、瓶颈及替代投入。重要条件紧随相关结论，不把它们压成末尾“尚待研究”。

大众版保留决定性因果链，省去可由附件承担的技术操作细节与台账，而非删掉理由。与专业版相比，它可以更长地解释概念和常识；没有必须更短的要求。正文以连贯段落为主，少用结论表、缩写和证据编号打断阅读；关键事实就近链接来源，末尾链接专业版和阅读范围。

## 4. 直白不等于粗糙

用“因为……所以……，但下一步还取决于……”展开具体机制。可用生活类比帮助理解，紧接实际对象说明对应关系和类比失效处；类比不能作为原理、经济性或不可能性证明。

对“成本”讲清什么成本、除以什么合格输出、差距来自哪些环节；对“更快”讲清快的是采样/仿真/子步骤还是最终任务；对“柔性”讲清可弯、可拉伸以及是哪一部分变形。读者不知道这些定义时，不应让一个技术词承担整个判断。

主观色彩来自明确取舍和理由，可写“我的判断是”“我不支持这类扩张”。不用贬称、讽刺、揣测动机或夸张绝对化来制造力量；同样不给已论证的裁定连续加“可能/似乎/尚无法”弱化。原文未声称的用途只作为外界扩展/待核假说，不归责给原作者。

### 4.1 正文回答技术问题，不讲审计内部流程（2.2.1）

大众版是在向读者解释这项工作的结果和投入判断。模型不能把写作指令、证据规则和自身工作记录改成正文。“需要比较”“应当核查”“不能推出”“本稿继承”不能代替实际调查后得出的答案。资料新读/继承、入口覆盖和方法适用域集中在文末/配套记录；会改变主结论的具体限制仍须在相关位置用日常语言交代。

每段应推进具体对象的认识：实际怎样做、哪一步出了什么问题、现有方案怎样处理、改善能否传到用户结果、为什么作当前资源取舍。凡删除技术名后能直接套到任何领域的原则性段落，改为该案的事实与推导，或移入方法说明。不能靠加长这类段落兑现“详细”。

不把研究任务交还读者。只有“需要看封装/良率/成本”的段落不够：能查清就查，能推导就推导，正文交代查到了什么和怎样影响决定。确有关键数据未取得时，写清缺的是哪项实际比较、它影响哪个判断，不用一串待补问题充当分析。

把审计词改成对象和动作：“相对系统收益”要具体到同一设备是否更准、耐用、省电、紧凑或便宜；“未建立需求”要说明现有设备怎样完成任务、为何不需要新增能力；“市场桥接”要具体到卖什么、谁使用、用户多得到什么。不能没有数据却编出具体改善或故障。

合理的判断应直接落到投入：“这项研究解决了X，现有方案已经解决了Y，但它没有增加当前任务需要的Z，因此我不支持按这个用途追加产业化资金。”这只是逻辑示意，字母必须换成该案已核机制与结果。科学增量、应用比较与未来资金分别作判断，不让抽象“其它用途可能存在”冲淡当前取舍，也不把不支持扩张偷换成已经证明所有用途价值为零。

写完再做删除检查：若删掉一段只会减少“如何评价研究”的说明，没有减少读者对本案技术、竞争和投入原因的理解，这段通常不应占据大众正文。正文需要让读者看到审计者已经完成的研究和判断，而不是看见一份等待别人填答案的审计清单。

## 5. 写作放行：读者能否解释

### 5.1 正文非分析文字上限：1%（2.2.2）

专业版与大众版**分别**执行硬性篇幅门：设A为正文中真正的实际分析字数，M为评价原则、待补问题及纯边界/免责/流程声明字数，必须满足 **100×M≤A**。超限不得放行，删除套话、移出必要记录或补足实际研究后重新写作。不得靠重复分析或拉长正文稀释比例。

- **A实际分析：** 针对本案的领域状态解释、成果结构与运行、具体创新、事实/机制推导、同任务比较、瓶颈及补救代价、科学/应用贡献和有原因的资金取舍。只罗列数据、术语、来源或重复结论不进入A。
- **M非分析文字：** 可套用于其它成果的评价原则；只要求别人补资料而没有给出答案的待补清单；只强调审计者不能保证/不能证明/未穷尽/不排除的声明；正文中的审计内部流程与新读/继承说明。句子混合两类时拆句或按片段计，不能将整段归为A隐藏套话。
- **必要的事实限制：** 具体结果与适用范围、误差、对照差异或缺失数据若与机制/结论一起解释其影响，属于A；单独写“证据不足/不能推广/有待验证”属于M。不得为满足比例删掉改变结论的事实、夸大确定性或把纯边界声明改名为分析。
- **计数范围：** 正文含决策摘要、解释性表格、脚注和结尾结论；更换标题或移到正文末尾不免计。题名、日期/对象标识、参考文献目录、纯引用标记、URL、独立证据/搜索/计算/阅读记录不进入A或M。记录只保留具体可追溯内容，不能在附录堆放通用免责或评价套话。大众版正文可用一行链接指向完整记录。
- **统一单位：** 每个汉字计1，连续的非汉字字母/数字串计1词，标点、空白与Markdown格式符不计；链接显示文字按内容计，URL不计。A=0直接不通过。例：A=5000字，则M最多50字；A=2500字，则M最多25字。

在配套写作记录保存正文版本、A/M及比例、分类依据和M的实际原句位置；可由工具计数，语义分类须逐句审阅，不能仅靠“不能/需要”等关键词识别。没有分类记录不能声称通过；数字通过仍须执行下面的实质读者检查。

对专业版与大众版分别指出正文位置，检查读者能否回答以下问题，以及能否用该领域具体的部件、读数和因果机制解释答案。标题、栏目或结论的出现不算回答：

- 本领域真正想解决什么，发表时与当前已有能力有哪些区别？
- 输入成果具体是什么，怎样工作/论证，最终测得或证明什么？
- 哪个部分已有，哪个部分是新增，其作用机制是什么？
- 最强替代怎样完成同任务，为什么它是有效比较？
- 主导瓶颈从哪里来，怎样损害结果或增加资源消耗？
- 输入对瓶颈/知识边界的边际作用是什么，哪些桥接成立或中断？
- 为什么作当前资金选择，什么具体证据会改变它？

缺项时先区分：知识未研究清楚则回到原始资料/领域模型；已经研究但正文太省略则补解释。篇幅、标题齐全、来源数量、术语密度均不是通过依据。示范改写只能验证本案例的解释方式，不声称已证明技能跨领域可靠。
