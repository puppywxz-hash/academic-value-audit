# 功能必要性、整机替代与能力迁移

有实际用途或应用潜力判断时，与 [需求协议](demand-and-impact.md) 一起执行。使用既有 C/E/R/CMP/P/M/J/CTX 台账，详表放需求记录；不新增 JSON 枚举。适配已有 G1–G12、M1–M9，补充本文件不代替其实际记录。

## 应用主张的支持程度与举证责任

评价中心是成果的原应用主张是否得到相称支持。逐项记录用途、作用/优势、范围、规模、时点以及“已实现/有条件潜力/设想”的原措辞；不得把核查任务扩成证明所有未来用途都不存在。保持否定结论的范围边界，但“没有排除其它用途”不能替代对原主张的裁定，也不提供正面价值依据。

对每项主张说明证据支持到哪个环节：需求与残余瓶颈、机制、系统能力、相对强替代的增益、可采用/可靠性、相称的效果与规模。缺商业记录不单独否定未来潜力；未来表述仍须有与其强度相称的具体路线及条件，不能只凭逻辑上未被排除。部分用途有证据不代表其它用途或广泛价值也得到支持。

允许结论为“已支持的具体用途及条件”“仅支持部件/原理验证，不能推出所称用途/优势/规模”“关键环节缺证，现有依据不足以支持该应用主张”“匹配反证表明该主张在所审范围不成立”。没有证据不自动等于事实为假。材料获取受限与原工作本身未提供依据分别说明，不将未读内容当作已确认缺失。

审计者提出的更苛刻/新用途可作为明确标识的研究问题，不作替成果保留高价值的理由。结尾交代实际原主张的支持范围、决定性缺口及补证条件；有关所有未来用途的逻辑边界仅在需要纠正绝对断言时解释。

## 1. 先问目标任务是否需要新增功能

将“柔性电子”“通用计算”“高性能材料”等标签改写成可观察任务：输入、动作、输出质量、工况、频率、寿命、资源及谁受益。区分作者应用主张、外界宣传、用户待核假说和审计者候选。候选不能冒充论文承诺；不把任意新场景扩成领域普查。

逐场景检索在用产品/设计、工作流程、采购/运行/失效记录及原始需求。提出删除或替换新增功能的反事实：若不用它，哪个终端结果变差，差多少，谁承担？先确定残余约束，再核查成果是否改善。只提高一个部件指标而不改变任务结果，应裁定该场景增量未证明；成熟替代已经满足目标，且新增部分无已证附加收益时，可以裁定本成果不是必要解决方式，当前应用增量缺乏依据。必要性不等于唯一性；不唯一仍可凭更低成本、更好质量或其他结果有价值。

不能以“做起来很难”“部件指标破纪录”“领域研究者都期待”证明任务重要；也不能以用户的负面直觉替代同样严格的取证。

## 2. 比较整个系统的可行架构

比较与成果完成同一任务的强替代，包含把困难功能移到另一部件、改变布局/封装/工作流程、部分保持刚性及不行动。说明功能、工况、代价和可行时期；技术相似不等于等效，厂家规格不等于现场性能。发表时创新和当前应用用各自时点基线。

例如穿戴不自动要求半导体拉伸；可以比较软外壳+刚性芯片、薄柔性电路、刚性岛+几何互连、中性面设计、波纹主动器件等。分别核查弯曲、轴向拉伸、双轴变形、曲面贴合、反复疲劳；先按目标任务筛选实际适用路线，不强制把所有路线都算一遍。软基底不能自动保护紧密粘接的脆性器件；金属厚度/宽度、强度、弯曲刚度、允许应变和疲劳不是同一指标。

产出匹配表：任务必要结果 → 在用/最强替代 → 残余问题 → 新增部分的实际作用 → 系统负担 → 有证/反证/未知 → 有边界裁定。不能仅列替代名称后声称已比较。

## 3. 把专用实验到用途的迁移拆开

写出当前实现实际允许的输入、操作、可调参数、输出与验证方式。目标用途另列必要能力，逐项核以下桥接：

| 必需桥接 | 需要什么依据 | 常见跳跃 |
| --- | --- | --- |
| 任务编码 | 真实输入如何进入装置、输出如何给出所需答案 | 数学相似当成完整求解 |
| 操作/控制 | 目标任务需要的算子、动态控制、条件反馈、精度 | 更大规模当作新增操作能力 |
| 质量与规模 | 真实实例、误差/噪声、复杂度或资源扩展 | 玩具演示当产业尺度 |
| 端到端优势 | 编码、配置、训练、校准、测量、后处理、失败重做及最强替代 | 采样/核函数快当整任务快 |
| 架构与归因 | 哪些器件/方法可复用、哪些关键能力须另造及其依据 | 同属材料/光子/量子路线便借用全部远期收益 |

专用装置可以执行正式计算任务，也可以有独立仪器价值；不通用不自动无用。区分可重新配置一个采样分布、可编程专用计算、理论通用、容错实现及实用广泛替代；这些不是同一个能力。必要操作不在当前装置中，增加规模本身也不引入这些操作时，可以明确裁定当前实现不适合所声称广泛用途。不能把这一裁定外推成整个物理平台永久无潜力。

提出“可升级”时说明补什么、已实现什么、资源/误差条件及能否保留原有优势。关键机制改变后应按新架构另审，只把有依据的组件复用价值归给原成果；理论可能不证明本装置是经济的升级起点，也不自动给予很高探索价值。对当前不适配有充分依据，无须等待销售失败；永久不可行仍需限定操作集合和相应证明。

## 4. 判定适用范围及价值大小

### 未来潜力的归因边界

领域或其他架构未来是否有潜力，与输入工作的价值是两个需独立举证的命题。理论通用性、同平台后续进展、可能的巨大市场，不能凭关联转成该工作的贡献；未建立具体贡献联系的潜力不计入本工作价值。纠正“整个路线永远不可能”仅修正该绝对命题，不上调输入工作的评价，也不为其应用主张背书。

若主张本工作对后续路线有贡献，需记录：本工作的具体新增知识/器件/方法 → 后续架构中的实际或有依据的条件性作用 → 相对先行/替代的增量改善 → 实现所需新增机制、代价及不确定性。仅有同材料、同作者、引用、技术相似或可复用设想不足以确认作用；不要求该贡献唯一或不可替代，但须证明实际增量。可核实组件或知识贡献时只评价该部分，不将新机器或整个平台的远期收益全归给本工作。

探索价值也要说明本工作回答的具体知识问题、获得的认识及相对已有知识的增量；不能用全领域潜力填补此项论证。未来受益尚未实现可保留有依据的条件性贡献，不写成已兑现收益。没有相称的作用依据则明确“未来路线潜力未建立与本工作的贡献联系，不作为本工作价值依据”。

先分任务，不由细分/专用自动推出低价值。小人群的严重未满足问题也可重要。估算有效适用任务量而非整个行业产值，区分需求、技术适配、采用与可交付；它们相关时不能随意乘独立概率。

可用有来源的上界：单位任务可改善的结果或可避免损失 × 有效任务数，再扣额外系统/生命周期负担。没有单位价值、分母或成本就保留符号阈值和实物结果，不制造市场数值；这是分析框架，不是已测净收益。成熟替代满足任务不证明最便宜，数据不足不得宣称全面支配。

结论分别回答：当前指定任务是否适配；比较增量是否成立；适用场景是否有实质重要性依据；迁移是否有可检验路径；扩张所需证据是否充分。允许“该场景价值低/当前不适配”“只成立窄范围知识贡献”“重要性未确定”，不给高低平均分。

## 5. 最低完成与停止要求

关键应用判断至少有一项实际执行的必要性反事实、强系统替代比较和必要能力桥接，或写明某项不适用及理由。搜索记录要显示功能/产品/流程词及原件回溯；已有证据可复用，无须为凑数量重搜。尚未处理重要已纳入场景，则范围分析未完成。只有“未见客户/商业化”不能满足此要求。

对决定性原理给公开可复核的推导/依据及适用域，现实参数回到实证；原理已能判当前不适配时不无限搜媒体。支持和反对材料使用同一标准。写出最可能改变结论的具体证据，并在两版与 JSON 同步，不靠空的质量数组声称通过完整审计。
