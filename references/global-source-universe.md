# 全球来源搜索与覆盖闭环

本协议规定如何把与产业、市场、公共和社会价值有关的可获取信息尽可能查全。它防止两种相反错误：以“世界范围不可能普查”为由少查现成来源；以及把有界价值裁定冒充为对所有现实事件的全称事实证明。

## 1. 两种“穷尽”必须分开，不能拿前者豁免后者

- **主体/交易普查**：逐一枚举世界上的每家企业、每笔私人交易、每位用户或每个项目。只有要估计全球数量/份额/覆盖率或作“全球绝无采用”等全称命题时，才需专门定义总体、分母和覆盖误差；它不是单项成果价值裁定的门槛。
- **可得来源调查**：系统发现并实际查询与问题有关的全球索引、官方登记、地区门户、行业/产品档案、学术与专利链、交易/用户/监管记录等；按检索结果扩展国家、语言、别名和新来源，逐条追完具体线索。这是每项应用价值主张的必做工作。

“没有完整全球名册”只说明不能声称做了主体普查，**绝不是少查来源的理由，也不妨碍对具体价值主张作直接判断**。可得来源调查必须从来源发现开始，按下文把所有适用、可访问的来源入口逐一纳入并实际查询。来源清单是不断更新的工作地图，不是假定存在一张先验完整的全球数据库；只要调查中发现有用新来源或可执行线索，就更新清单并继续查。不得用“全球主体普查不必要”替代来源调查，也不得把“可能还有未公开记录”当作不调查公开路线的理由或把未证收益保留为正值。

## 2. 先把待审判断拆成可观察问题

逐条写清成果标识、作者原文主张、审计者新增场景、终端任务、用户/买方/付款方、产品或服务、预期结果阶段、地区、截止日，以及什么证据能支持/反驳。将下列结果分层，不互相代替：

1. 技术转移、许可或获取机会；
2. 原型、现场试点或可供产品；
3. 采购、付款、部署、运行或重复使用；
4. 对客户、公共服务或社会产生的可归因结果；
5. 相对替代方案的净收益、持续性、可扩展性和经济性。

一次许可不能冒充产品销量，产品不能冒充持续采用，采购不能自动冒充终端收益。某一层没有证据时，保留已证实的低阶段结果，再独立判断更高层。

## 3. 建立可审计的全球来源地图

来源地图至少评估以下家族；每个适用家族要落到实际入口、具体查询和结果。按主张/技术/使用地区选择入口，不强求无关数据库，也不得只写“Google 搜索”“专利网站”或“新闻”。

| 来源家族 | 要发现并按适用性实际查询的来源 | 主要用途 |
| --- | --- | --- |
| 技术与学术演进 | 综合及专业文献/引文库、预印本、会议、学位论文、标准组织、技术报告 | 前沿、独立复现、后续沿用、替代与负结果 |
| 知识产权与转化 | 全球专利索引、相关辖区官方专利局、大学/研究机构 TTO、许可/发明目录 | 专利族、权利变化、许可、技术包和具体归因桥 |
| 资助、项目与组织 | 主要公共资助/合同/结题门户、学校和实验室档案、法人/公司/并购/破产档案 | 资金关联、项目进度、责任主体、持续或退出 |
| 产品、供给与准入 | 主管机构产品/召回/认证登记、产品目录、手册、厂家/经销档案、标准 | 型号、真实架构、供给阶段、适用范围、停供 |
| 采购、交易与用户 | 全球采购索引、相关国家/地区采购门户、合同/授标/付款/验收、客户和用户记录 | 买方、实际用途、交易阶段、部署、续购和运行 |
| 需求、替代与结果 | 政府/行业统计、终端用户规范、真实任务研究、运行/临床/公共服务数据、替代品与退出记录 | 需求、任务门槛、强替代、结果和反证 |

发现来源的起点包括：一般网页和学术搜索；引用与被引用；官方机构的数据库目录/API/使用说明；专利分类、TTO、资助、监管、采购和行业协会目录；论文、专利、产品与合同中的实体链接。至少记录使用过哪些起点以及由此发现了哪些专门来源。

对一个来源家族只查一个聚合网站，不自动算覆盖该家族。要核对聚合网站的地区/年份/记录类型覆盖，并查其未覆盖但适用的官方登记、专业数据库、当地语言门户或第一方档案。发现多个互补且可访问的入口时，应逐一查询；若判断某个入口重复、低信息量或不适用，记录根据，不能静默省略。

### 3.1 来源发现和逐入口检索是两项硬工作

不能只从模型已知的几个网站开始。先用学术/网页检索、官方数据库目录与 API 目录、专利局/TTO/资助机构/监管与采购机构目录、行业协会和产品目录、已命中记录的引文/链接，主动发现来源入口；将发现结果记入来源路线台账。对每个适用来源家族，至少回答并留证：

1. 该领域有哪些全球索引、国家/地区官方登记、行业/产品档案和第一方记录入口；用什么目录或发现查询找到它们？
2. 每个入口覆盖哪些地域、语言、时期和记录类型？与已查入口是否互补？
3. 每个适用、可访问入口实际用什么查询和筛选？搜到多少结果、查看了哪些结果范围、导出了哪些记录、哪些候选被排除及理由是什么？
4. 哪些命中产生新的国家/语言/法人/产品/用户/买方/技术名称或登记入口？它们是否均已回到原始记录？

**来源路线台账的覆盖债务必须可见。** 每条路线的状态限定为“已查询并筛读”“已查询、结果集过大且说明筛选/抽样框”“访问受阻并完成替代尝试”“经对象级证据确认不适用”“待查”。“待查”或存在可执行的可访问来源，即表示来源闭环未完成；不能因已有很多搜索结果、没有单一全球名册、来源可能重复或预计命中率低而改标完成。若公开记录集合太大，须说明数据库覆盖和去重方法、时间/地域/类型过滤、检索式、结果数及审阅规则，并进一步查可导出的记录、官方分类或互补数据库；便利抽样不得伪装成全面查找。

来源目录本身也须检查：检索主要目录/API说明中的相关数据集和地方登记；查到的聚合平台应与原始机构/地区入口交叉校验。若一条路由需要账号、API key、机构订阅或 GUI，且当前环境没有访问权限，先试公共网页、导出、镜像、档案、关联机构页面或替代登记；仍不可访问才记阻断。可向用户请求访问材料，但不因等待用户而停止其它独立路线。来源发现途中出现新的具名入口时，把它纳入台账，不以“已完成四类调查方向”封口。

## 4. 执行多路检索并按线索递归扩展

每项应用/价值主张至少实际执行以下互相独立的方向：

1. **成果向外**：DOI、题名、作者/发明人、机构、项目号、专利号及历史别名 → 引文、后续项目、专利/许可、公司、产品、用户和退出。
2. **任务向内**：作者声称的功能、产品类别、买方任务、终端输出、竞品名称和当地行业术语 → 找到所有可能的实现架构与供给方，不能只搜输入技术名。
3. **通常痕迹**：先判断该结果若发生通常会由谁留下何种记录，再查询对应产品/准入、公司、采购/合同、部署/客户、用户/社会结果等来源。
4. **反向查漏**：搜索替代路线、失败/停供/召回/项目退出、未采用理由和相反结果；核对命中是否只是作者、同一学术圈、同一资助链或新闻稿互相转载。

英文和输入语言只是起点。按权利/研发地、原主张地域、已发现的供应链/买方/用户市场扩展到相应国家和本地语言。新出现的法人/旧名称、产品型号、专利辖区、买方、经销商、用户、标准号、资助号或行业术语都生成后续查询。对重要原件应打开并记录实际读到的内容；搜索摘要只算线索。

## 5. 每条入口记录状态和调查影响

| 状态 | 必须记录 |
| --- | --- |
| 已查询并取得/阅读 | 数据库/机构、地区/语言/年份、精确查询和筛选、访问日、命中、原件及阅读范围、新线索 |
| 已查询无相关命中 | 同上，并说明索引覆盖和查询限制；不能把无命中外推为世界无事件 |
| 暂时无法访问 | 实际尝试与错误、替代官方入口/API/档案/地区来源；还会影响事件存在、归因还是仅金额/数量 |
| 不适用 | 对象级理由；“难找”“没有统一名册”“不像主要渠道”本身不是理由 |
| 尚未查 | 具体下一步来源与查询；若可能改变裁定，调查不能标为完成 |

若官方入口动态/不可索引，至少尝试其 API、下载数据、替代官方登记、数据库镜像、档案、交叉引用或当地语言入口。受阻记录不得被静默删去；若可能影响某结论，要说明如何调整判断强度。

## 6. 停止条件：清空可执行来源覆盖债务；没有来源家族捷径

应用价值调查只有在以下条件同时满足时才可标为“可得来源调查已闭环”：

- 通过来源发现渠道形成了具名路线清单；每个适用来源家族中发现的全球索引、相关国家/地区官方入口、关键行业/产品来源和第一方档案都已逐项查询，或给出有证据的对象级不适用/实际访问阻断及替代尝试。不得只查搜索引擎、单个聚合站或每类任选一个来源。
- 成果向外、任务向内、通常痕迹和反向查漏均已执行；覆盖原主张所涉地域，并沿实际线索扩展到相关国家、当地语言和独立原始记录。
- 每个能改变结果是否发生或是否归因的已发现线索均已追至原件，或明确记录阻断；按来源独立性去重，不能把转载数量当作多源确认。
- 逐项复核来源路线台账，相关的“待查”项和可执行覆盖债务为零；最后再做一次针对漏源/漏词/漏区域的挑战检索（官方目录/API、同义词/旧名/分类号、至少一个由命中引出的新地区或语言、强替代/退出），记录新发现如何处理。
- 完成来源反向查漏：另从独立于原研究团队/资助宣传链的索引或用户/供应/监管/交易记录出发，挑战当前结论；若该检索又带出适用来源或可能翻转的具体线索，回到台账继续调查。

闭环只证明“在本次声明的对象、结果层和审计时点，已通过多种发现机制定位所有适用且现实可执行的已知/新发现来源路线并逐项处理；已发现的具体线索均已处理”，不证明世界上所有信息都已找到。报告必须展示路线表、查询/结果范围、覆盖债务和阻断。不能用固定轮数、若干来源家族的勾选或“最近没想到新来源”代替上述闭环。若最近搜索仍带出新的相关公司、数据库、地区或可执行路线，不能宣布闭环，应继续。若工作资源确实中断且仍有可执行路线，报告必须标“来源调查未闭环/结论为当前证据下暂定”，并继续给出可用于决策的当前证据结论；不能声称尽责调查完成。**市场分母/总体未能枚举，只限制市场总量或全球普及率，不可作为拒绝判断该成果在已审结果层有无价值的理由。**

全球市场规模、份额、渗透率或“全世界绝无应用”是更强的总体主张，需要定义结果总体/分母、主要地区、记录可观察性和覆盖误差；不能从成果归因搜索外推精确全球市场数。但这一点只限制总体数字和事实绝对零值，不削减单项成果应用价值审计对全球可得来源路线逐一发现、检索、追线索的义务。

## 7. 如何给结论，避免“零”和“无法证明”来回摇摆

报告先给直接、可用于决策的结论，再交代边界：

- 若任务/架构/对照/可靠性或经济证据显示主张不成立，明确说明**哪一项主张、在哪个任务/条件下、被哪项事实或推导否定**，不能只列“尚未证明”。
完成适用调查仍无有效结果证据时，明确列出所查行业/任务并说明该主张不能支持本轮扩大投入；机制反证与计量零值另按来源判断协议论证。这项有界价值裁定不等于全球所有隐蔽收益的数学总量已被证明为0，也不外推到其他层级。
- 有许可、原型、产品、交易、使用或可归因社会结果时，逐项保留其真实阶段；之后才讨论规模、净效益和可扩展性。
- 只剩具体不可访问材料，且它确实可能改变事件存在/归因时，把该分支标作“调查受限/未完成”，列出替代路线和对结论的影响；不得用它抹去已确定的其它结论。抽象地说“也许有秘密交易”不能把无证收益变成正值，也不能阻止对已完成证据作出裁定。
- 不能从单个来源无命中推出客观不存在；但完成路线饱和后，不能因无法逻辑排除所有潜在隐蔽事件而回避价值裁定。完成适用调查仍无有效结果证据时，明确列出所查行业/任务并说明该主张不能支持本轮扩大投入；机制反证与计量零值另按来源判断协议论证。

## 8. 报告覆盖表

| 价值层/主张 | 来源家族 | 具体全球/地区入口 | 地区/语言/年份 | 精确查询与命中 | 原件和阅读范围 | 线索追踪/独立性 | 未查/阻断及影响 | 对裁定和资金建议的作用 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |

至少附一张主要地区/语言覆盖表。不得把入口清单冒充搜索记录；不得把搜索结果冒充已读原件；不得把“覆盖全球候选来源”写成“完成全球主体/交易普查”。
