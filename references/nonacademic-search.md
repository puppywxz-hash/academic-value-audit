# 产业、市场和社会资料的系统搜集

涉及应用/社会主张时与 [需求分析](demand-and-impact.md) 联用。目标是取得能检验具体命题的记录，既包括支持，也包括可行替代、不采用及不利情况；搜索数量和来源身份不定真假。执行本协议不等于已验证需求或效益。

## 1. 先建立搜集计划

同步执行[专业社区与从业者调查](practitioner-debate.md)。寻找失败、未采用、隐性工序和使用代价的实际讨论；不能只在论文/机构/供应商资料之间闭环。每个实质批评转成来源需求并给处置，不以论坛数量当覆盖率。

按 [输入分支](input-discovery.md)先定对象/代表范围和候选关联：奖励获奖者/成果、个人、团队代表角色、无全文项目各有发现路线。先从成果拆功能/载体再找机构/记录；后续发现的转化主体、项目号、专利号和产品型号回填身份与关键词，不让第一次查询绑定所有后续资料。

从 claim/context 拆取证任务，固定时期/历史截止、地区、产品或服务、使用/购买/付款/受益角色、型号/法人及功能单位。每项写明待区分的解释、需要什么观察、资料可能由谁产生、哪种缺失限制结论。纯知识评价只加载相关先行工作/非论文技术史，不强制全部市场渠道。

在 search-log 中保存以下矩阵；每行对应一个实际取证问题，而非一条宽泛搜索词：

| claim/context、问题与范围 | 预期原记录及产生主体 | 实际渠道/查询/过滤/日期 | 执行范围与状态 | 原件 S/E 与位置 | 关系/适用/缺失 | 对判断影响及下一项 |
| --- | --- | --- | --- | --- | --- | --- |

区分未执行、已搜有命中、已搜无命中、索引可见、原件已读、访问受限及不适用。转回现有质量 search_lanes 时使用其真实枚举；本表是可读操作记录，不新增 JSON 字段。目录存在、查询返回结果和取得能支持命题的原件分别记录。

## 2. 根据问题生成机构与记录清单

| 搜集分支 | 定位路线 | 核证重点 |
| --- | --- | --- |
| 使用任务、残余问题 | 使用/运营方、维保方、公共服务部门；手册、运行/费用/质量/失效及服务缺口 | 实际任务、在用基线、时间/工况、暴露分母、选择与漏报 |
| 要求与选择 | 采购人/采购门户、需求调查、技术/商务附件、变更/取消、成交、合同、验收及续约 | 原项目/合同编号、提出理由、阶段、关联/补贴、付款/采用的取得范围 |
| 产业与供给 | 匹配客户/供应商法人，披露系统、产线/产品文件、分部/风险附注、贸易/统计及方法 | 路线/型号、投入/实际产出/产能、口径、分母、统计修订和产业链重叠 |
| 替代与不采用 | 相同任务的现有/竞争路线、系统/流程重设计，退出/停用/未采购的原记录 | 可行性、同条件服务与全成本；实际原因而非审计者猜测 |
| 制度、安全与环境 | 对应地区/用途主管机构、技术原条款、认证测试、召回/执法及环境/安全记录 | 适用对象/日期；技术条款与效果分开；投诉/召回不能直接给总体风险率 |
| 技术标准与测试/验收 | 发布机构/官方目录，功能/ICS/CCS/委员会 → 编号/部分/版本 → 原条款及法规/合同引用 | 按 [标准检索](standard-retrieval.md)核版本链、原文、性质/适用/方法匹配；目录或程序不等于使用门槛 |
| 奖励规则与底层成果 | 设奖/主管机构，原条例/办法/细则、年度指南/评审规则及提名范围/支撑资料 | 按 [奖励适配](award-assessment.md)核年度/奖种/子类/等级、必要条件/可选路径及权重；范围及取得限制 |
| 社会结果 | 目标人群行政/统计/调查原表、方法及实施/覆盖、可信对照或贡献研究 | 结果而非活动量；样本/选择、反事实、额外作用、分配和不可观察部分 |
| 先行/工程创新与专利 | 原论文/早期产品手册/技术报告、专利全文及家族/状态，按功能和分类检索 | 历史可获得时点、实质机制/权利要求；同族不是多次创新，授权/件数不证价值 |

清单按对象具体化：凡适用且可访问的门户都必须实际查询；对不适用入口须按对象写明理由。查可能具有其它名字/用途的客户任务和历史技术，避免仅用材料热词生成供应方报道清单。海外案例只在制度、工况和口径可迁移时作当前对象依据；但全球来源用于候选发现时仍应查询并记录其覆盖范围。

## 3. 依次扩展查询

1. **功能与流程发现。** 先用任务/产品/服务及问题词，分别查现有方案和残余约束。例如“任务 + 维护/故障/等待/运行成本/需求调查”，记录实际执行字符串。应用名未知时从原主张提候选，再核实，不能把候选当已证需求。
2. **分类与同义词扩展。** 从匹配原件提取产品/行业分类、技术分类、旧名/缩写、型号、项目编号、法人及别名；用不同词与不同记录类型补查。分类代码版本与边界保留，不能认为某代码覆盖全部相关需求。
3. **机构/数据库定向查。** 对产生记录的主体使用站内检索、目录/分页、可用公开 API 和站点限定搜索。分开地区/时期/服务层级。某工具不支持布尔/日期或只能返回片段时如实记录，不能写成执行了严格过滤。
4. **原件前后追踪。** 从公告回查附件/依据，从同一项目跟到合同、变更、验收和后续；从统计原表回查方法/修订，从专利回查优先权/家族/说明书，从效果研究回查实施和数据。阶段缺失就保持缺失，不用后一条新闻补齐全部链条。
5. **竞争解释与失败查询。** 分别找相同任务的替代、未采用/流失/退货、约束及失败原因；支持与不利材料用相同范围/方法标准筛选。并购或停用不自动归因技术失败，负面关键词命中不自动是反证。
6. **缺口驱动迭代。** 若新原件显示不同任务/基线/时期/技术身份，先更新矩阵和受影响记录再补查。发现新术语/竞争路线时追加查询并保留原因；不断出现相同转述不能冒称新增验证。

保留查询、数据库/网址、日期、过滤器、实际可见结果数、页/游标和筛选理由。已知相关记录可以用于检查查询是否能找回，检查失败后修订；未知全集时不能因此声称真实召回率达到某百分比。搜索排名前若干页仅是读取范围，不能称覆盖全行业。

## 4. 取得、去重与结构化

按 [获取方法](acquisition-methods.md) 保留实际原件/可见范围和位置；索引摘要仅支持索引可见事实，不声称读完原条款或完整方法。用户提供资料也核对产生方式、定义、覆盖与使用权限。

- 同一项目的招标/合同/验收是关联事件，保留阶段证据；新闻转载、同一公告镜像和同一统计系列合并观察来源。
- 同一企业改名、母子公司和产业链交易标明关系，不能默认独立客户或累加收入；独立实验与共同需求前提分别审。
- 专利家族保留成员/版本及优先权；依分析目的选择并记录家族定义，避免把同一发明的多国申请算多项创新。
- 数字附原表/条款、单位、分母、时期、地域、版本、方法、调整/修订；名义/实际价、库存/流量、产能/产出、报价/成交及关联/非关联不得混用。
- 问卷/访谈资料至少核查资助/执行者、目标人群、抽样/招募、时间、问题原文/测量工具、响应/权重及限制。缺方法时不能给总体需求比例；LLM 模拟受访者不是实际客户资料。

取得的观察接回 S/E/C、关系、P/M、requirements/comparisons、quality/method audit；搜集过程及缺失解释仍保存在 search-log。行业报告可用于术语和定位，关键数字追原表或透明方法；找不到则保留有出处的报告说法及推断限制。

## 5. 覆盖、停止与输出

本节与[可得来源穷尽调查与价值裁定](research-saturation-and-zero-rule.md)共同执行。每条主张先拆解任务/实现/结果层，再从成果标识向外追、从任务/产品类别向内反查、找结果通常留下的记录，并主动找替代/退出/失败。适用的官方/专业入口、本地语言和结果线索必须实际查询；“完整全球名录拿不到”不豁免任何已知可行来源。为每条主张填写覆盖矩阵，入口名称不算检索记录，搜索摘要不算已读原件。对不相关来源须按对象级理由说明不适用，不作机械国家清单。

具体、可访问、可能改变事件有无/归因的来源和线索未处理时必须继续。停止前逐路线记录查询式、时间、地区/语言、原件取得/阅读范围、命中阶段、来源关系/利益依赖、全部派生查询和最终反向挑战；说明仍缺的资料是否可能改变事件层裁定。先用[全球来源搜索与覆盖闭环协议](global-source-universe.md)建立具体入口清单，清单中的适用全球数据库、国家/地区登记、行业资料和本地语言来源必须逐项查询或说明客观阻断/不适用；不能用固定轮数、少数结果页或“没有其它已知线索”自证充分，也不能因全球名册/普查无法完整枚举就跳过可访问来源。完成适用调查仍无有效结果证据时，明确列出所查行业/任务并说明该主张不能支持本轮扩大投入；机制反证与计量零值另按来源判断协议论证。若有 option、产品、免费发放、购买或用户结果，按已证阶段保留并分别裁定归因。受阻资料只在可能改变事件有无/归因时导致分支未完成；若只影响金额、分配份额或 ROI，就单列这些数值未知，不把已完成结果层降为“无法判断”。预算/权限限制如实记录。

### 5.1 检索结果如何进入价值裁定

检索矩阵完整不是结论本身。按可归因结果而非“还不能排除”估值：

1. 对每个原文用途和纳入的终端任务，从技术/作者/机构/专利/关联项目扩展到功能关键词，再追查最有信息价值的独立系统、需求方、产品、采购/监管、部署/运行或社会结果原件。按实际线索补足相关语言、地区和记录渠道；不适用/低优先级路线写明对象级理由，不能笼统略过具体线索。
2. 对产品/交易主张，分清科研演示、可购买供给、获准使用、试点、一次付款、持续部署/复购及用户净结果；对社会主张，查实施、覆盖、结果、对照/反事实、额外作用与分配。每一阶段的证据只支持对应阶段。
3. 逐个核对候选结果是否由输入成果产生、目标机制是否实际采用、它相对强替代是否带来终端增量。相关领域存在需求或产品，但归因链断开时，不把其价值分配给输入成果。
4. 按[可得来源穷尽调查与价值裁定](research-saturation-and-zero-rule.md)执行全部适用路线和线索。完成适用调查仍无有效结果证据时，明确列出所查行业/任务并说明该主张不能支持本轮扩大投入；机制反证与计量零值另按来源判断协议论证。除非封闭总体与记录捕获充分，不声称现实结果绝对为0。同时列出来源路线、任务/地区/语言覆盖、原件阅读、线索闭环、反向查漏及阻断项。较低层的许可、购买、免费发放或用户结果必须保留，不能由高阶段判断抹掉。只要有具体可查且可能翻转事件/归因的线索就继续；不把全球名册当门槛，也不因其缺失跳过可行搜索。用一句短范围说明限定未公开记录，不要用它撤销当前裁定。
5. 若已有可归因的实物效果、社会改善、技术转移、付费购买或部署，即使金额/覆盖面未知，也保留对应事件/结果，并将金额、规模、长期净收益或因果贡献分别标为未识别。若某个具体的高信息量原件拿不到，准确说明其可能改变什么结论；继续其它可行路径，并只限制该分支。未证实的潜力不给正向收益信用。

完成适用调查仍无有效结果证据时，明确列出所查行业/任务并说明该主张不能支持本轮扩大投入；机制反证与计量零值另按来源判断协议论证。它不是宣称全球绝无隐蔽事件，也不是售价、历史资金 ROI、科学贡献或未来潜力为0，更不外推至整条研究线/其它结果层。报告分别记录关联研究线事件、输入成果归因、成熟阶段、金额/净收益、实际来源路线和剩余具体缺口。合同或金额未公开不能抹掉可确认事件；若有具体可访问合同/产品/用户线索可能证明目标成果已产生该层价值，仍须继续查。

交付：按问题优先级排列的全球来源搜索地图和实际搜索矩阵、纳入/排除/版本及关系清单、原始位置/数字和取得范围、逐问题覆盖、停止理由与剩余具体缺口、它们限制哪些判断。旧内容可复用但检查时点/修订，不把历史公开痕迹当当前成功。G4/G5/G6/G9/G10 按原质量协议实质执行；不设与对象无关的机械国家配额，但不能据此略过适用全球/地区入口或本地来源；每条来源清单中的路线都要有“已检索/无命中/阻断/不适用”状态和具体理由。

## 6. 可复用方法与技能

- [K-Dense market-research-reports 入口](https://github.com/K-Dense-AI/scientific-agent-skills/blob/main/skills/market-research-reports/SKILL.md) 1.5：可选市场定义、来源/主张映射及估算；[官方来源路由](https://github.com/K-Dense-AI/scientific-agent-skills/blob/main/skills/market-research-reports/references/official_data_sources.md)用于定位，[证据模型](https://github.com/K-Dense-AI/scientific-agent-skills/blob/main/skills/market-research-reports/references/evidence_model.md)用于来源接回。API/许可以执行时原始服务为准，未安装/运行候选不冒称可用；市场场景与上市数据不直接回答本成果真实需求/社会收益。
- [CDA-AMC Grey Matters 官方说明](https://www.cda-amc.ca/grey-matters-practical-tool-searching-health-related-grey-literature)：借鉴按主题/机构搜非期刊资料、记录查询/可访问性/结果；原清单以医疗/HTA 为范围，不照搬成通用产业名单。本次说明经官方搜索索引读到，下载清单未成功取得，不声称完整清单审阅。
- [WIPO 2015 专利景观指南](https://www.wipo.int/edocs/pubdocs/en/wipo_pub_946.pdf)第 8 章：借鉴范围定义、同义词/分类迭代、数据清理与家族口径；不采用其中经验召回率数字作为已达到的通用质量阈值，专利景观不验证市场与净收益。
- [AAPOR 披露标准](https://aapor.org/standards-and-ethics/disclosure-standards/)：适配已取得调查资料的方法审查；所读页面引用 2021 版准则，不冒称核证了所有最新准则，也不据此自动发问卷/访谈。

本协议为针对学术价值审计的适配工作流，已有学术检索及 PRISMA-S 记录规则继续使用；不将第三方指南/技能权威本身当实证质量证明，也不复制整套第三方原文或执行未审脚本。
