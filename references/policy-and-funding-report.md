# 面向政策制定者与经费管理者的专业报告

2.0正文以[研究主流程](research-engine.md)和[决定性论证](../assets/decisive-argument-template.md)为主线，解释瓶颈、增量、强替代和资源选择。下述覆盖维度用于查漏，不能代替论证。没有配置、任务或工作量的价格算术不作为预算依据。

默认专业版的主要读者是政策制定者、项目/经费管理者；技术同行可由推导和附录复核。目标是让无本领域训练的读者理解：投入究竟购买哪种可靠知识/能力/公共结果，成本与时间是多少，为什么选它，何种证据支持继续/扩大/调整/停止，以及热度是否与投入理由一致。

这调整专业版的内容和解释深度，不新增第三套判断。专业版与大众版仍共用两层评价和台账；用户指定读者/篇幅优先。使用 [专业模板](../assets/report-template.md)及 [成本与需求重建](cost-demand-reconstruction.md)，保留原任务边界。

涉及“纳税人的钱值不值得”、已发生公共经费的科学回报或是否追加资金时，必读[公共科研投入评估](public-science-funding-assessment.md)。不能将财务金额未知作为停止科学回报分析的理由，也不能以科学增量单独宣称单位投入划算。

## 1. 对象、路线和方向分别评价

区分所给论文/项目的具体增量、它所属路线及更大领域。为判断输入贡献和投入理由，主动补够学术/产业背景与强替代比较；这不是自动审计全方向全部项目。报告标明背景取证范围、代表性和未审部分。

可以指出该工作的理由不足、某种扩张缺少依据；若要裁定全领域经费配置，必须有方向内主要路线/项目、预算/时期和共同瓶颈的相应覆盖。方向有其他潜力不为输入工作归因增益，输入工作失败也不独自证明方向所有研究无值。需要更广覆盖才能下的宏观结论明确未决，不代拟不存在的预算方案。

## 2. 背景必须形成解释

执行[成果解剖与解释深度](explanatory-depth-and-public-writing.md)建立对象结构/流程、先行—新增差别和瓶颈因果链。专业正文按非本领域决策者的知识起点讲解，不能把深入介绍只留给附录或来源原文。

### 学术背景

说明领域试图解决什么知识问题、为什么问题重要、已有关键认识与当时强先行、不同机制/路线、尚未解决的缺口。解释本工作改变了哪条认识/能力边界及其大小、可靠性、复用与反例。首次引入术语和决定性指标时说明直观含义；不要以奖项、名刊、论文数量或大数字代背景。

### 产业与社会背景

从实际需求、价值链和在用方案起步：谁遇到什么问题，现有方案为什么不足，约束在器件还是整个系统，实际任务量/支出/受影响结果，谁付款/受益/承担风险。沿研究、验证、试点、交付、持续竞争各阶段区分证据，解释理想实验优势为什么传到或不能传到终端结果。

有商业秘密或零散使用时查可观测代理并披露覆盖。基础探索无明确应用可直接说明知识目标和相关公共理由，不为凑章节编市场需求；应用宣称强的研究不能靠基础身份回避应用审计。

## 3. 两种跨领域比较

### 知识与研究路径

以共同问题/能力/可验证认识组织邻近或交叉学科的理论、算法、测量、实验与工程方法。比较它们已实现什么、条件、资源、可靠性、新增认识和复用；判断本工作是否只是改名/迁移或确有增量，不只比较同领域自选基准。

无法以同一终点排序时给差异与各自目标，不给“每篇论文价格”或将不同学科主观分数相除。对于公共探索投入，比较回答同一关键问题的资源与辨识力；只得到不同问题结果就不能写成已被低成本替代。

### 最终产业与社会任务

按同功能单位/质量/工况比较成熟技术、改良已有方案、另一架构、软件/制度/服务替代以及不新增投入。方案须当时/现在可得且真正可交付目标，不以落后的稻草人或某个最难子步骤代表全部经典/产业方案。

展示从输入工作到系统/用户结果的桥接，比较合格终点、全成本、可靠性、规模、切换条件及外部后果。说明谁优于谁、为什么、在哪种任务量/成本/寿命下翻转。跨技术路线不是跨所有政府部门随意排名；跨目标预算比较须有明确政策目标/偏好和数据。

## 4. 投入产出的政策解释

分别回答历史事前选择、截至审计日兑现与下一笔行动。先给科学/研究回报判断（知识、方法/数据、研究能力/共享平台及可核后续作用），再独立判断历史公立投入的实际支出、科学成本效果/机会成本能否识别，以及下一笔钱支持什么。产业价值没有被证明时，不跳过科学增量评估；科学贡献明确时，也不据此把实际历史投入判为最优或单位成本划算。

用实际金额或有依据的范围、任务/知识/社会产出、时间和归因组成投入产出表；无法共同货币化则用有单位成本效果、目标达成、替代和阈值，不强行汇总ROI。致谢基金号、批准额、拨付额、合同额、实际支出与社会资源成本分开；没有历史决算时给科学回报裁定，并精确说明value-for-money/机会成本未识别的变量，不能只以“没有账目”结束此段。

预算、科研产出、转化收益、公众结果和资助额外作用分开。商业销售、科研设备市场、就业、论文和奖励不自动等于社会净收益；政策使命/战略标签也是待论证理由。评价公共资金需求时核具体外部性/知识溢出、私人投入障碍及资助相对其他可行干预的增量，不因市场弱自动推出应该由政府全额承担。

成本正文给核心模块推导和主要驱动，附录给规格/多价格/工时/计算详情。回报正文解释单位结果和它为什么有意义，给最有利合理情景、关键未知、翻转条件及机会成本；模型结果不能全归本论文。已知成本部分、未知/不可估值结果和执行未完成项清楚分列。

## 5. 热度与价值证据是否一致

先证明“热”：依问题和时期选可核经费/项目分布、论文增长、投资或传播指标，分别显示原始分母/价格口径、关系和覆盖。不必全部取得，无真实记录就写热度尚未核实；融资承诺不当资金实到。

再与独立的知识/应用/投入证据对照：

| 可能的结论 | 必须说明的依据 |
| --- | --- |
| 热度与贡献/投入理由相称 | 具体问题重要、增量可靠、必要条件及相关资源收益支持；明确知识与商业理由分别成立到哪一步 |
| 只能支持探索，不能支持产业扩张 | 学术/机制问题值得辨识，但终端需求/可靠性/成本/桥接缺证或失败 |
| 宣传/投入规模超出证据 | 强价值或扩张承诺需要的证据缺失/被反证，规模/阶段与已核作用不匹配 |
| 低热度但具体价值扎实 | 观察到稳定解决问题/复用和增量，不以报道少作为低热度唯一证据 |
| 无法判定一致性 | 热度、总体经费/覆盖或收益资料不足，指明已可判输入工作的部分 |

不把热度本身计作价值加分或扣分；成功投资/失败公司不替单项技术归因。逐一写出显著标签/倍率/新闻/资金规模可能诱发的**错误推论**（如窄基准优势被理解为通用任务优势、科研仪器采购被理解为终端服务需求、连续专项被理解为独立价值验证），然后用精确定义、分母、最佳替代、用户结果和独立归因拆解。结论使用“可能造成的理解风险”，没有受众研究或具体决策记录时不得说某类人已被误导或某圈子操纵舆论。

对资金建议做“注意力剥离”：不看期刊/团队标签、标题修辞、新闻稿和预算规模，只留明确知识问题、可复核增量、强替代、成本与里程碑，再复判下一笔行动。若行动改变，说明是实质证据还是声誉/传播标签造成；热度只在明确且另行取证的国家战略/议程目标中作为政策背景，不作为技术收益代理。

## 6. 资金行动要有条件和退出规则

按评价目标分别给：基础探索/复现，解决关键未知，工程验证，应用试点，扩大部署，共享/合并，延后/转向/停止。相同证据可支持小规模辨识但不足支持大规模产业化；写具体理由，不能一律“建议继续研究”。

每项可比较行动记录要买到的交付、关键未知、合理成本/时间或范围、成功/失败门槛、什么结果改变行动、何时退出/止损。预算数值与资金份额有来源/模型才给；不知道目标预算时只给条件/阈值与相对选择，不编建议投入金额。历史投入与未来投入分开，沉没成本不自动支持追加。

基础研究验收可用具体可辨识问题、可复核结果/排除解释、可复用工具及成本控制；应用验收用同终点强替代、真实环境、全成本/可靠性、真实需求和客户/公共增量。不可控未来重大突破不充当短期验收承诺。

## 7. 专业版的内容完成要求

采用“决策摘要—背景—两层分析—跨领域/路线比较—模块成本与投入产出—热度一致性—行动—证据附录”。可嵌入既有章节，不要求第三份摘要文件或固定页数。

每个影响资金判断的章节都有：问题/背景、竞争解释/替代、已核原证据、推导或计算、结论/未知及对行动的影响。表格承载比较，正文解释因果和取舍；只填结论表和引用不算专业分析完成。无统一字数，篇幅足以让读者理解决定性链条，重要推导不能全部藏入附录。

决策摘要可由非同行独立读懂：评价哪项投入、主要学术与实际结果、成本/需求依据、哪类行动获支持、哪些不获支持及翻转条件。专业详版保留技术可复核性；大众版充分展开直白解释，保留同结论/条件，不另造更强政策建议。

方法参考：[Green Book 2026](https://www.gov.uk/government/publications/the-green-book-appraisal-and-evaluation-in-central-government/the-green-book-2026)的目标、无新增干预基线、额外作用、备选方案和监测/评价相关部分。采用分析结构，不套英国法律、贴现率或声称其认可本技能。读者定位、两层/热度对照和模板是本项目适配设计。
