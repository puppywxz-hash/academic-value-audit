# 专业社区、从业者经验与争点调查

在领域重建和关键争点取证时执行。目标是发现论文背景常略过的限制、失败经验、成本结构、竞争方案和比较漏洞，并追到能够裁定它们的依据。批评的发现优先级可以很高，其真实性仍需逐命题判断。

## 发现：从实际问题和做事的人出发

按对象选择中文及相关地区语言的知乎、Quora、X、Reddit、专业论坛、研究者博客、Stack Exchange、PubPeer/OpenReview、公开邮件列表和项目 issue。它们是候选入口，不要求机械地逐站打卡；至少实际尝试与领域相关的专业讨论入口和应用/制造/运维从业者入口，后者不适用时说明原因。

- 同时用技术名/旧称/产品名与故障、良率、标定、维护、停产、退货、成本、替代、量产、failure、benchmark、replication、yield、teardown、field experience 等具体词检索。增加中性和支持性查询，避免只搜“骗局”形成结果偏置。
- 从有实质内容的作者、评论回复、会议问答、图表和引用继续追踪，查原帖及完整争论，不能停在热门摘录。中文命中生成英文技术词，英文命中生成中文工艺/行业词。
- 找接触约束的角色：操作/制造/采购/维护/客户、竞争路线研究者、独立复现者及作者本人。头衔、点赞数不替代知识依据；身份无法确认时写“自述/署名未独立核验”，不做隐私身份挖掘。
- 区分同一事实的转载、独立经历和独立推导。多名人士沿用同一错误假设不增加验证强度；单个可靠反例也可能推翻全称主张。
- 记录查询、日期、帖子/评论位置、可见范围、访问失败和新增争点。用户粘贴全文记为“用户提供文本，原页未核”；不得写成已读取原网页。访问失败尝试合理公开替代入口，再索取用户已有文本；其余研究继续。

## 拆解：把尖锐表达变成可以查的命题

每条可能改变评价的意见保留独立记录：

| 项目 | 所需内容 |
| --- | --- |
| 原始出处 | URL/评论编号/日期或用户文本；简短准确释义；相关身份及利益关系 |
| 命题 | 对象、条件、时间、观察或推论；同一段里的历史、物理、价格和全称结论拆开 |
| 独有洞见 | 揭示哪项被遗漏的需求、约束、弱基线、隐性劳动、机会成本或价值前提 |
| 机制与预测 | 若其成立，系统的哪个量应怎样变化；失败原因是物理限制、当前工艺、规模/价格，还是需求不存在 |
| 核查路线 | 最有区分力的实验/工艺参数/运行日志/成本分项/算法/客户记录及合理替代入口 |
| 最强回应 | 作者回应、反例、更新型号、不同场景及其他解释；回应是否正面解决原批评 |
| 处置 | 采纳、部分采纳并限定、驳回、待核；列依据和对结论/资金行动的具体影响 |

“贵”须拆成同场景合格输出的总成本；“没用”拆成谁的任务、原替代、增益和代价；“做不大”拆成随规模变化的损耗/缺陷/时间/良率；“造假/骗经费”拆开技术事实和动机指控，不用前者自动证明后者。

## 核查：原始资料可以直接产生于社区

1. **可检查的推导、代码和反例**：核输入、假设、适用域和结果。公开博客里的原始证明不必等期刊发表才有证明力。先理解并尽可能复核，不能只转引其作者声望。
2. **第一手测量和工程记录**：查装置/版本、工况、样本选择、测量过程、失败分母、日志和可复现性。真实局部失败不自动代表全行业。
3. **当事人经历**：允许作为有归属的事件证言，注明未独立确认的范围；特别追查价格口径、停机、返工和采购原因。个人经验没有总体分母，不能生成普遍发生率。
4. **转述、预测、情绪或身份断言**：追原件或保留为假说。没有可检验内容的不进入技术结论；待核的具体批评仍列进研究队列，不能悄悄丢弃。

按证据内容决定强度，不规定“所有社区内容只能作线索”。同样，新闻/论文也不能仅凭载体获得更高真实性。两方有利益关系均披露，不据此自动否定其论证；不按正反人数投票，不要求为了平衡而给同等权重。

## 必须导致研究动作或明确排除

批评应改变关键词、系统模型、强替代、参数需求或行动门槛中的至少一项；若没有改变，记录它重复了什么或为何不相关。对足以翻转主要决定、公开且可取得的线索继续查，不能只在附录列个论坛名。

常見的可检验路径包括：便宜原料是否降低每单位合格产出的总成本；材料最优值是否来自低载量/过量辅材/选择样品；算法是否只赢过均匀随机或暴力基线；“兼容现有产线”是否仍需重新验证、改变配方和承受爬坡损失。这些是待查问题，不能作为预制负面结论。

## 报告与完成门

正文给出最重要批评的技术内核、实际核查、最强回应、裁定及行动，来源详情放底稿。不能以“存在争议”结束。正面突破、负面限制和明确反例用同一证据标准。

没有检索到相关讨论时，列实查入口及直接技术研究退路；尚未检索、只看到摘要、关键回复未读不能标完成。未知的影响要具体，例如某报价影响金额但不改变架构能力结论。

方法借用：[AACODS清单](https://www.library.sydney.edu.au/content/dam/library/documents/support/doc_aacods_checklist.pdf)对作者/准确性/覆盖/客观性/日期/意义的逐维审查。本技能把它适配到技术争论，取消按机构名气自动评级；不宣称AACODS提供技术真伪判定或要求机械的网站配额。
