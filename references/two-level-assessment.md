# 两个层次的价值判断与组合结论

默认报告分第一层“学术与创新价值”和第二层“产业、商业、市场及社会价值”，再给组合结论和资源含义。两层共用原始台账，分别有主张、比较、结论范围与质量放行；不将两层的高低默认平均成总分。篇幅按任务，正文可短但不能将两层混成“有价值/没价值”。奖励评价另按 [适用评选规则](award-assessment.md)处理资格、共同必要条件及有出处的偏好；保留两层实际贡献，不用奖项得分覆盖事实。

实际裁定须按[分析充分性协议](analysis-adequacy-and-determinate-conclusions.md)重建原时点/当前领域状态与真实任务端替代，并从证明、反例、边界、匹配系统比较中给出证据能支持的最强结论。该协议优先于仅列论文/场景/未知的表面完成；不要求无范围的绝对确定性。

## 1. 第一层：学术与创新价值

回答：成果是否可靠，相比它提出时的先行工作增加了什么，新认识或能力的重要性如何？先恢复实际做法、结果和条件，不以作者包装的新名词直接认定新机制。

### 1.1 比较对象与证据

- 搜同一问题、机制或功能的最接近先行工作，也查相关领域、早期技术报告、产品及专利原件；“小同行内没做过”不自动等于真正首创。相似工作从语义/机制/任务识别，引用数与期刊名不作默认筛选。
- 当时的新颖性用当时已经公开/可获得的先行依据；当前用途/后续贡献另用当日证据。后来出现更强方案不自动否定当年的贡献，较早申请但当时未公开的材料须说明历史可见性。
- 对比定义、材料身份、机制/结构、方法、样本、工况、资源投入、输出、误差及复现。性能结果在可比条件下比较；若改变成本、纯度、规模、环境或测试条件，差异披露，不能把数字上升全归于方法突破。
- 原始主张/测试支持、独立验证、推导边界和数据缺口分别记录；未独立复现不自动造假，实测高性能不自动确认全部作者解释。

使用下表，由 E/P/CMP/M/J 生成，可纳入 report.md 第一层：

| 最近先行工作与当时可见性 | 已经能解释/实现什么 | 本成果实质新增 | 条件/资源/口径差异 | 验证及反对依据 | 学术/创新意义与范围 |
| --- | --- | --- | --- | --- | --- |

### 1.2 分别评增量和意义

1. **科学知识**：新现象/机制、理论或可验证界限、减少不确定性、排除解释、拓展有效条件。指出解决了哪个真实知识问题，不用“基础价值”概括替代证据。
2. **方法与工程创新**：新方法、架构、工艺或可重复能力，相比强先行方案新增什么。学术/工程创新和可规模交付分开；实质工程贡献不因缺少新物理而自动低。
3. **性能与认识极限**：相同或有说明的条件下突破多少，提供了什么新认识。昂贵材料得到极端优异性能可以有高学术价值，但极值本身不足以自动判重大创新；简单增加资源、改变分母、挑样本或弱基线也可能产生极值。
4. **有效资源/复现/负结果**：工具、数据、可靠复现及反证具体新增或被实质复用的部分，不以新颖性唯一衡量。
5. **研究问题的重要性**：解释增量改变了哪些知识、方法或可能用途。对于应用导向研究，引用第二层已核实需求/瓶颈及限制评价其选题意义；第二层尚未完成时标为待核。学术圈多数/资助使命不直接证明意义。

每项给实质差异、有单位的结果/界限、可靠性及意义理由；不能给无依据的创新百分比或通用 100 分评分。明确允许“可靠但增量有限”“学术贡献明确、应用意义低”“创新性一般但复现/资源价值明确”。应用价值低不删除已证知识；学术增量低也不能由未来市场规模补成高创新。

### 1.3 系统创新判断的执行顺序

不能从一个极值、引用率、奖项、专利、专家判断或“新架构”称呼直接裁定知识贡献较高。对关键创新主张按以下步骤实质比较；必要深度取决于决定性主张，不机械要求每篇都有全部指标。

1. **恢复实际贡献单位**：把名称/愿景拆成问题、输入/输出、机制/结构、边界条件、算法/证明、材料/工艺、接口、实际新增能力和资源。分别列作者声称新在哪里及审计者可确认新在哪里；系列论文分开独立增量、延续验证与重复展示。
2. **构造最强先行解释**：搜原时点同领域及相邻技术史，判断先行方法是否已经解决相同实质问题。按机制和能力映射，不因不同术语遗漏，也不因表面功能相似就认定等同。首创、独立重现、迁移适配、实质改造和组合创新分别解释；现成部件组成新系统仍可能解决此前未解决问题，不能自动称无创新。
3. **比较知识与系统性质**：知识型看新解释/预测、可区分竞争机制的证据、定理条件/边界和不确定性减少；方法/工程型看功能、正确性、安全/失效、扩展、可靠性、兼容、效率及资源的相关整体取舍。相同任务、服务质量、样本/规模、输入条件及资源下比较；性能提升伴随成本/约束变化要披露。单项最好不等于整体领先；不同用途的合理取舍不能被强行混成一个指标。
4. **查新增部分的作用与归因**：如果移除/替换所称创新，已有办法还能解释或实现多少？优先使用已报告的消融、对照、证明/反例、匹配改造或资源归一比较，查效果是否来自新增机制，还是额外资源/数据/测试条件。审计者的移除设想只是反事实分析，未实际执行不得写成实验；证据不足限制归因，不自动判定没有作用。
5. **判断实质增量的重要性**：是否解除真实知识/方法瓶颈、拓展可验证范围、建立可复用能力，或改变研究/实现路线？理论有效但解释增量有限、工程整合有效但原理首创未证、某条件性能高但迁移边界窄等可分别成立。大困难、大投入、热度及共同使命不自动证明解决的问题重要。
6. **处理最强反对与结论翻转**：比较最强相关先行、等价解释、弱基线、不可比工况、负结果和共同前提；指明什么新证据改变“重大/有限/未能确认”。整体创新判断的强度受决定性前提限制，不能把几个薄弱指标相加制造高确定性；未知项不当零。

上述最近先行表之外，按需要附“创新单元—旧方案能力/限制—新增原理或结构—检验/归因—系统取舍—知识意义”表。报告给出沿证据链形成的理由；多个指标都高只支持其已验证范围，不自动证明重大科学突破。

**透明计算类型的应用示例**：先辨认计算在哪里执行、代码/数据/状态如何传输、启动与调度/缓存/失败机制、异构适配依靠什么，再比较原时点的分布式系统、无盘/网络启动、流式装载、虚拟化等相关路线。服务器执行的远程显示与客户端执行不能只因“经网络使用系统”而判等价。若所称新增机制已在先行工作中存在，可限制该原创性主张；若组合确有新能力，核新增条件、证明及系统代价，再分别评科学与工程意义。这里只规定分析方法，未读取完整获奖工作簇不作整体结论。

## 2. 第二层：现实价值

在实际任务和需求证据上，用 [系统搜集](nonacademic-search.md)、[需求与影响](demand-and-impact.md) 及 [计算方法](computation-methods.md)逐场景展开：

| 子项 | 核心判断 | 必需区分 |
| --- | --- | --- |
| 产业/工程使用价值 | 相对可行替代，能否改善任务、系统及全生命周期服务 | 实验峰值/系统增量、可用/可制造/可交付、使用收益和成本 |
| 商业价值 | 特定供应/运营主体能否在真实条件下交付、获利并维持业务 | 客户收益/供应商收益、报价/全成本、关系/补贴、风险及价值获取。专利授权不自动等于可保护收益 |
| 市场价值 | 哪些独立任务/客户会选择，规模、支付和持续竞争力如何 | 适用需求/可服务/可争取、产能/销量、意向/付款/复购、预测/持续记录。细分市场不自动低价值 |
| 社会/公共价值 | 实际额外结果、外部后果及分配，相对其它办法是否值得 | 私人支付/社会需要、活动/结果、关联/因果/贡献、技术/论文/资助归因、不可货币化部分 |

按当前实现、未来条件和原时点分别裁定；未来潜力不要求已经商业化，也不能冒称已经兑现。第二层须覆盖原文、奖项/申请/宣传材料的全部用途主张，并依[全球来源搜索与覆盖闭环协议](global-source-universe.md)逐项实际查询全球索引、相关国家/地区登记、行业数据和本地来源：既从成果标识向外追，也从任务/产品类别向内找实现者，查询可观察结果通常留下的来源，并主动找强替代/退出。沿每条线索查原始依据，不能用“用户只给了一篇论文”“只约定了几个任务”或“不是市场普查”缩小调查。没有完整市场名册时，也必须查询所有已知适用、可访问的来源，并扩展到资料指向的主要市场和本地语言。未公开资料若只影响金额/规模，层级照常裁定；若来源清单中具体可查项仍可能改变事件有无或归因，该层调查未完成。完成适用调查仍无有效结果证据时，明确列出所查行业/任务并说明该主张不能支持本轮扩大投入；机制反证与计量零值另按来源判断协议论证。这是有界价值裁定，不等于全球绝无事件的证明。

## 3. 必要条件与致命约束

只有适用且有资格作为必要条件的要求（gate_eligible）或有明确假设的情景，才支持相应不适配判断。学术性能优势不能补偿真实应用所必需的安全、寿命、成本或系统功能失败；假设不当现实硬门槛。

逐约束写：任务/时期/路线、原要求及理由、相关结果/失效机制、与替代的比较、可绕过/改造路径及代价、是否仍保留所称增量、最强反对证据、结论范围/翻转条件。

| 已有证据 | 可作的判断 | 不可自动升级为 |
| --- | --- | --- |
| 匹配实测表明当前实现达不到必要条件 | 当前实现无法满足该任务，应用主张在范围内被反证 | 整个材料/领域所有未来路线永远不能用 |
| 跨合理参数/改造条件仍不具净收益，或强替代在完整相关指标上支配 | 在这些任务/条件下应用价值很低，扩张缺乏依据 | 未审其它用途也没有价值 |
| 原理/数学界限证明指定机制在所有允许设计内均达不到必要条件 | 在明确机制/设计/条件内不可行；其推导需质量审查 | 对未纳入新机制、不同任务和所有未来工艺的永久判决 |
| 只知存在尚未解决问题、参数缺失，或应用检索未完成 | 对应潜力有条件/尚未证明或分支未评估 | 已证致命缺陷或永远失败 |
| 完成适用调查仍未找到有效结果证据 | 列明所查行业/任务，裁定该应用回报不能支持本轮扩大投入；已确认的技术转移/采购/使用等按阶段保留 | 将搜索缺席当作世界范围事实总值为零；把未归因的团队后续产品算给单篇工作 |

不要以“未来也许有办法”消解已充分证明的当前低价值；新结构或条件确实改变决定性约束时才调整范围。1000 次测试未失效不当寿命仅 1000 次。断言“永远无法应用”所需的范围和机制证明明显强于“该用途当前不合算”，没有这种证明使用后者或条件性界限。

## 4. 组合结论与行动

摘要至少包含两层分别的判断、最关键证据、取得限制及桥接状态；再说明第一层知识是否提供独立探索理由，第二层应用缺陷是否限制承诺和转化规模。组合是有解释的判断，不是默认加权总分。

| 第一层 / 第二层 | 组合描述（仍须对象证据） |
| --- | --- |
| 知识/创新高，应用低 | 可有明确学术贡献，具体用途的应用价值很低；学术成果不能作为该转化扩张的充分依据 |
| 知识/创新有限，现实效果高 | 新知识增量有限，但实际交付/社会效果可有高价值；不强行包装成原理突破 |
| 两层均高 | 既有实质贡献，又有匹配现实增量；规模和论文/资助归因仍单独核查 |
| 两层均低 | 在已审范围可以明确整体增量小或低价值，列出贡献/需求/替代的具体依据 |
| 任一层缺证 | 保留已成立层，另一层标待核/未证明；不能把未知填成低或高 |

用户要求组合判断时，可写“学术价值较高，但所宣称用途的现实价值低，应用导向综合评价受限”；若要判断总体值得投入多少，先明确评价目标、成本、机会成本及 M1/M3/M5/M6/M7。公共/商业投入、原理探索和成果转化分别给相称行动，不由第一层高或第二层低自动决定所有研究应继续/停止。

若对象是奖项，组合解释的重点由实际奖种/子类/等级/年度条件决定。先核全部共同必要条件和允许路径，再处理正式权重或定性重点；缺证不冒称不达标，已反证不靠另一层补分。成果实际价值、奖项符合性及规则合理性分别报告，不从“获得某奖”推出高贡献。

## 5. 既有契约与报告

两层是呈现及评价组织，不新增 JSON 层对象。第一层映射 value_profile 的 academic，具体探索理由可映射 exploratory；第二层工业/商业/市场分项用 industrial 下不同 scope/notes 和 judgment/context IDs 表示，社会用 social；跨层资源判断用 resources。允许同一维度有不同明确范围，不混加。

每层的真实关键结论仍建 C/J、CMP/M、质量与方法记录；低/高写在有依据的 notes 和正文，assessment 继续使用已定义的 established/conditional_potential/not_demonstrated/contradicted_in_scope/not_applicable/not_assessable，不能新造 low/high 枚举。scope 标明层次、子项、任务及时间，不能将“学术高”代替证据集合确定性。

纯基础研究的第二层仍简明展示适用边界和可判断部分，不编用途/产业模型；用户明确只审一层时遵循其范围，并列另一层未审。报告使用 [模板](../assets/report-template.md)，详表可进附录；两层正负判断均服从 G1–G12。
