# 输入、取证与持久化执行

2.0先执行[研究主流程](research-engine.md)建立领域问题、竞争解释、模型和争点，再按本文件发现/获取/持久化；不要先填完整报告。定向方法试验可交备忘录和来源/计算记录并明确范围，完整审计保留原契约。

## 1. 入口与任务锚点

接受单篇/列表/文件、会议/专利/项目/奖励材料或人/组线索。创建唯一运行目录，推荐 `audits/<对象短名>-<审计日期>/`，先记录目标、纳入范围、验收范围、时点、当前进度、缺口和续跑点。所有用户可读文本 UTF-8。

从自然语言自动生成 input.json，遵循 [输入契约](input.schema.json)。默认当日审计、环境时区、中文、多维分项、包括与主张相关 SI、无总分、无新增付费服务。分析模式按用户范围：明确文献/个人默认 comprehensive，团队代表范围按下面授权/样本规则，用户全范围要求优先。`evaluation` 自动补齐；未知决策主体可 null，资源范围写未知，不把检索费用上限当项目预算。

默认报告两层，按 [两层评价](two-level-assessment.md)组织：第一层以历史最近先行比较学术/创新，第二层按纳入任务展开产业/商业/市场/社会，再给组合与行动。用户只要求一层时保留范围；无实际用途不编第二层模型。

默认按 [双版本交付](report-delivery.md)生成专业详细版和科普大众版，共用台账/两层裁定；用户只要一版则优先其要求。第一性原理及量化按决定性分析单元展示，不能仅写一个“分析过”标签；没有适用数据时解释不能计算和可用阈值/定性。

专业版默认以政策制定者/经费管理者为主要读者，读取 [政策报告规则](policy-and-funding-report.md)，在输入贡献所需范围补学术/产业背景、跨学科/同任务替代、热度一致性及经费行动。凡问公共科研“值不值得”须另读[公共科研投入评估](public-science-funding-assessment.md)，分开评价科学增量、历史价值相称性和下一笔经费。设备价格必须标出实际购买对象/单位/金额状态及本轮回答的问题；跨国或全球价格问题按相关地区的原始采购渠道查证，不能将科研仪器成交额当终端应用市场。

用户可以指定范围、历史时点、样本或输出。普通少量输入不需要补表。需要确认的实质缺口是同名身份、互相矛盾的对象认定、特定访问权限，以及单一排序/资金建议的决定性偏好。集中询问；不依赖答案的分支继续。

## 2. 发现与归属

少量线索按 [输入分支](input-discovery.md)及 [发现记录](../assets/discovery-record-template.md)执行：对象身份/范围 → 关键词/成果载体 → 原件候选 → 关联/版本/归属 → 工作簇 → 分析/决定性缺口队列。每类输入的下一项和取得限制都有对应记录，不能只列可用数据库。

- 单篇：核对 DOI/题名/作者/年份/版本/出版商；预印本、正式版、修订和重复报告关联，保留各版本差异。
- 多篇：逐篇纳入，按数据/机制/贡献聚类，不能把最终效益在多篇重复计数。
- 个人：核对单位、主页、ORCID/持久标识、时期和归属证据，查论文/项目/专利/资源及转化；默认发现可识别元数据并按工作簇逐批深读已纳入相关工作。抽样须有用户授权、实际发现框和明确限制。
- 团队：核机构/时期/成员/方向，按用户本技能约定选覆盖主要主题/阶段/角色的代表人物；走个人分支并补团队直接项目/资源/产品，合并共享贡献。代表入口不自动限制全范围发现；只深读代表样本则记录 sampled/purposive 与授权来源、发现框/选择/未覆盖和外推限制，不能声称团队全集。用户要求全面时继续处理已纳入相关工作。
- 项目/申请书：只有名称/编号/简介也先定身份/阶段，找公告/摘要/公开任务、报告及项目号对应成果；已读目标、背景和审计推断分开，无全文不重建方案，事前与实际兑现独立处理。
- 非论文：读会议原报告、专利权利要求/实施例、计划书原目标与资助记录、获奖官方范围和其底层工作。授奖/授权记录支持事件，不证明技术价值。
- 奖励：按 [奖励适配](award-assessment.md)自动发现奖种/子类/等级、评奖/颁奖年度、正式获奖工作簇与原规则。实际价值和规则符合性分别建情境；历史截止与规则版本不由当前宣传材料替代。
- 奖励成果发现与规则同步：先查正式获奖者/单位/范围，再拆创新单元/用途/形式，分别追原论文、专利/家族、转化主体/许可/产品和使用/效益记录；相同关键词不自动归属该奖，后续成果另定范围。
- 至少用持久标识、题名/作者和版本关系查重复；自动候选不直接确认身份。未知归属不放入个人总体结论。

可用合法索引、机构目录、出版商、仓库和专利/项目数据库发现。OpenAlex、Crossref、PubMed 等元数据可作线索，全文与实证仍回原文。服务能力、认证、额度和许可在使用时核查，不硬编码历史配额；没有某连接器不阻断其他途径。

## 3. 原始获取与位置

实际检索/提取按 [获取方法](acquisition-methods.md)；需要专门能力时先读 [路由](capability-routing.md)，核实实际可用性与子任务要求。不为每篇运行所有技能，也不把技能存在当已取得原件。

优先用户文件、出版商合法 HTML/PDF、作者/机构仓库和已有授权访问。取得关键方法、图表、SI、数据/代码或原始事件记录；合法范围内保存原文件、来源、版本、取得时间及可见片段。

正文缺 SI、只读摘要、只有元数据、访问失败分别记录。取得相关图表时核对图例、工况、单位和材料身份；复杂图/扫描件需用可用查看/OCR 工具并说明读取误差。局部读取不称全文审查，索引数字不冒充核对过的全文结果。

原文位置优先 PDF 物理页码+印刷页/图表编号、HTML 章节/表段、报告版本或视频时间。稳定定位不足时记录取得范围和影响，不造页码。原始来源与全文下载许可分别说明，引用短必要片段，公共交付不复制全文。

访问失败记录后换合法途径。只有权限/付费决定确实阻断关键判断时询问；不反复询问已经授权的访问，不绕过限制。未取得的材料保持未知并限制相应结论。

## 4. 主张、要求和搜索

作者原主张、第三方说法、审计者识别的命题分别登记。保留提出者、范围、时态、日期、基线、critical 及依赖。先写证据需求，再执行 [质量协议](evidence-quality.md) 的六渠道；日志可写 direct_retrieval，不能捏造未执行检索。

第一层按 [系统创新比较](two-level-assessment.md)拆实际贡献单元、最强先行解释、知识/系统性质、归因与取舍及问题意义；必要时跨领域及非论文工程记录，原时点创新与当前应用分开。单项性能/引用/获奖不能作为高贡献的充分理由。第二层非学术取证按 [系统搜集](nonacademic-search.md)记录机构/原件/查询与覆盖，不能只搜成果名和报道。

对应用门槛先核查提出主体、原始条款、实际任务/地区/时期、测试程序与失效定义。标准规定测试方法不自动规定使用需求；竞品性能、作者设想和自选假设不自动作为现实淘汰门槛。

技术标准执行 [专项检索](standard-retrieval.md)：功能/产品/分类 → 官方编号/版本/状态 → 合法原文/引用条款 → 适用/约束/可比性。只读目录就记录目录范围，未找到明示门槛转有来源使用推导或保持未知。

奖励执行规则矩阵：原条款/年份 → 资格/共同必要条件/可选路径/等级/偏好 → 两层证据与支持状态。必须同时满足的条件先审，权重后审；定性重点不转换成虚构比例。缺公开评分/代表作时保存范围，不推测内部评审结论。

查需求方运行、验收、维修、采购、复购、实际过程和可行替代；行业/政府载体也可能只是转述。跳出热词，用功能、系统、早期名称和其他路线检索；不设支持/反对/圈内外数量配额。

产业/社会/应用潜力关键主张必须按 [需求与影响流程](demand-and-impact.md) 独立建立需求端记录：分角色/任务，查现有方案及残余问题，再连系统增量、采用、净收益和归因。需求调查/采购条款也检查理由与共享前提；社会分支不能只核查市场支付。使用 [需求记录模板](../assets/demand-analysis-template.md)，填入既有 E/requirements/comparisons/P/M、M1/M8 及相关质量记录，不能仅列若干来源视为已审需求。

## 5. 情境、工作簇与迭代

涉及经济性/公共投入时执行 [成本与需求重建](cost-demand-reconstruction.md)及 [记录模板](../assets/cost-demand-record-template.md)：直接总额缺失后从成本驱动、匹配类比、需求/交付约束和翻转阈值继续。历史支出/当前重置/未来增量不得混算，公开设备交易只能在规格与范围匹配后接入模型。

公共经费的科学回报、历史支出是否物有所值以及下一笔投资属于不同判断：执行公共科研投入专项参考。每条价格标金额种类、币种、地区、单位与被买对象。用户问全球价格/市场、或目标产品显著跨国供应/采购时，填成本/需求记录中的跨地区覆盖表；只取得一地或仅有未核原件时明确source-limited，禁止输出“全球价格”或市场大小。

实际分析按 [计算方法](computation-methods.md) 确定数据是否足够；以 [分析记录](../assets/analysis-record-template.md) 保存输入到模型到判断的过程。原始测量、报告数字、重算结果和情景预测分开，未知关键参数时改用阈值/定性或受限结论。

按 [决策协议](decision-quality.md) 建 context 与 M1–M9，保留事前、截至审计日和未来视角。新证据改变身份、基线、前提、版本或参数时，登记变更及受影响 ID，重算相关模型和判断，再放行；未受影响材料复用。

工作簇报告实际新增认识、可靠性、连续问题解决、实质复用、应用兑现与具体公共资源。归因依靠贡献声明/职责/实际记录；第一/通讯作者、PI 和名头不单独证明全部贡献归属。

## 6. 产物与完成语义

经济分支结束须有成本口径、实际取证、适用的重建尝试、需求与单位收益、替代/最有利情景/逆向阈值检验或具体不适用理由。尚未执行可行且决定性的步骤记 partial，不能归为来源受限而声称经济审计完成；路径已经执行但仍不能识别决定性参数则说明受限结论与翻转变量。单项用途能力被反证可直接判断不适配，但不因此称财政整体回报已判。

涉及应用时，结束前按 [功能必要性与能力迁移](functional-necessity-and-transfer.md) 审查实际记录。只有“公开商业证据未发现”而无必要性/系统替代/能力桥接，不得称已完成应用潜力分析；明确尚未执行的分析和续跑点。原理充分支持当前不适配时允许负面裁定，不用所有未来用途未知消解该判断。

同一记录派生 Markdown/JSON/CSV。推荐最小产物：

```text
input.json               自动补齐的输入与选择
report.json              事实台账、quality_audit、method_audit
report.md                专业详细版、决定性分析/原始引用及两版映射
report-public.md         同源科普大众版、数字/原理含义与限制
evidence.csv             原始位置、观察、条件及判断关联
对象与成果发现.md         各输入身份/关键词/候选关联、团队代表选择、无全文项目与下一项
requirements.csv         真实要求/推导/参照/假设与适用性
标准与奖励规则.md         涉及时的标准版本/条款矩阵及奖励规则—证据映射，分别保存
需求分析.md              有应用/社会主张时的逐任务证据链及角色/采用/影响
成本与需求重建.md        涉及经济/资金时的口径、分解/类比、范围及盈亏平衡检验
method-checks.csv        M1–M9 的范围、适用、完成与影响
search-log.md            实际查询、筛选、访问失败与覆盖
calculation-log.md       有实际计算时记录输入、公式、单位、结果
CURRENT_STATE.md         当前事实、已完成、下一项、失效记录
sources/                 仅保存合法取得且需要复核的材料
```

相关表无实体时不填假数据；在报告中说明不适用及原因。source_coverage 与 status 分开：完成约定范围且披露取得限制可 complete/source_limited；还有已纳入工作未处理则 partial/in_progress 并续跑。未知真实总量不将已发现列表称全集；归属、全文、SI、深读和关键裁定覆盖分别报告。

技能说明不代替实际工具执行。缺检索/计算能力时保存能判断的部分、限制和恢复所需材料，不宣称已经自动抓取、复现或校验。计划中的校验器/独立复核未运行时如实说明。

报告及标题/图表的判断强度逐项回到同一放行依据；大众版不新增证据，不算独立审查。更正台账/模型/判断后同步两版，不只修改容易传播的摘要。当前任务完成、设计规范齐全和技能运行可靠分别判断，不能互相证明。
